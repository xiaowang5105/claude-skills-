# Hexie —— 文献综述全流程

三个 Claude Code skill。

---

## hexie-writer

```
1. Plan Mode → 读全文，定位文献综述段落
2. 前置检查与文献方案
   ├─ 段落大纲 / 文献清单 / 文献关系 / 文献数量
   ├─ 逐篇联网验证
   └─ 缺文献 → 搜索 → 3个方案(论证大意+论文身份+文献群落) → 用户选择
3. 范例匹配 + 句层拆解
   ├─ 索引定位 → 三层比对 → 提取模板
   └─ 句层拆解表(字数+功能+证据数+关联词) → 写和查共用
4. 逐句套模板改文
   ├─ 4.1 原文核对(方向/内容/归属) → 表格全"是"
   └─ 4.2 句层比对(同一拆解表✓/✗) → 针对性修改
5. 引用准确性自检(方向/内容/归属)
6. 联网验证 + 时间线 + 逻辑链(A→B→C→D)
7. 保存 → 提醒运行 hexie-check
```

---

## hexie-check

```
1. 读全文 → 定位文献综述
2. 识别组织方式(八选一)
3. 打开范例文件 → 索引定位
4. 13条清单：结构组5条 + 语言组6条 + 忠实组2条
5. 引用准确性核对(方向/内容/归属)
6. 联网验证 + 逻辑链检验
7. 生成报告
   ├── 全"是" → 输出终稿(md+docx)
   └── 有"否" → 修正清单 → 回hexie-writer → 再跑hexie-check
```

---

## hxpdf

```
1. MinerU GPU PDF → MD
2. 对比一：MD vs PDF → 差异对照表1
3. PyMuPDF 全篇逐页抽取 + 异常页检测
4. 对比二：PyMuPDF vs MD → 差异对照表2
5. 联网补缺(AI上下文匹配，~85%命中)
6. 修正 + 去公式图片
7. 修正汇总表
```
