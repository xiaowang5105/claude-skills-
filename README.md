# Hexie —— 文献综述全流程

三个 Claude Code skill。

## hexie-writer（写）

```mermaid
flowchart TD
    S1["1. Plan Mode → 读全文定位文献综述"]
    S2["2. 前置检查：大纲/清单/关系/数量"]
    S2A["联网验证每篇论文"]
    S2B["缺文献？→ 按关系角色搜索 → 输出3个方案"]
    S2C["方案一：论证大意+论文身份+文献群落"]
    S2D["方案二：..."]
    S2E["方案三：..."]
    S2F["推荐 → 用户选择"]
    S3["3. 范例匹配+句层拆解"]
    S3A["索引定位 → 三层比对 → 提取模板"]
    S3B["句层拆解表：字数+功能+证据数+关联词"]
    S4["4. 逐句套模板改文"]
    S4A["4.1 原文核对（方向/内容/归属）→表格全'是'"]
    S4B["4.2 句层比对（同一拆解表✓/✗）→针对性修改"]
    S5["5. 引用准确性自检（方向/内容/归属）"]
    S6["6. 联网验证+时间线+逻辑链(A→B→C→D)"]
    S7["7. 保存 → 提醒运行hexie-check"]

    S1 --> S2 --> S2A --> S2B --> S2C --> S2D --> S2E --> S2F
    S2F --> S3 --> S3A --> S3B --> S4
    S4 --> S4A --> S4B --> S5 --> S6 --> S7
```

## hexie-check（查）

```mermaid
flowchart TD
    C1["1. 读全文 → 定位文献综述"]
    C2["2. 识别组织方式（八选一）"]
    C3["3. 打开范例文件 → 索引定位"]
    C4["4. 13条清单检查"]
    C4A["结构组：引用位置/段首/转折判断先行/连接词密度/收束句"]
    C4B["语言组：标点/叙述主体/AI腔/引用简洁/语病/句间节奏"]
    C4C["忠实组：词汇来源/终极检验"]
    C5["5. 引用准确性核对（方向/内容/归属）"]
    C6["6. 联网验证+逻辑链检验"]
    C7{"7. 全'是'？"}
    C7A["输出终稿（md+docx）"]
    C7B["输出修正清单 → 回hexie-writer定点修正 → 再跑完整hexie-check"]

    C1 --> C2 --> C3 --> C4
    C4 --> C4A --> C4B --> C4C --> C5 --> C6 --> C7
    C7 -->|是| C7A
    C7 -->|否| C7B
```

flowchart TD

    H7["7. 修正+去公式图片"]

    H6 --> H6A --> H6B

    H6C --> H7 --> H8 --> H9
```

## 范例库

22个已发表论文范例，八种组织方式。每个含四层：前8000字原文(去公式图片) + AI上下文分析(段落判断/句层功能标注/引用群落关系图) + 结构大纲 + 正文段落。

├── hexie-writer/

```

MinerU 3.x + PyMuPDF + CUDA版PyTorch。模型：`mineru-models-download -s modelscope -m all`
