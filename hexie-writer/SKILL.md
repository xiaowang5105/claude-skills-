# 文献综述修改（学术散文风格）

## 执行流程

**Step 1. 进入Plan Mode，读全文，定位文献综述段落。**

**Step 2. 识别组织方式**（八选一，见下表）。不确定时列出选项询问用户。

**Step 3. 前置检查：缺一不可，即使推断也要向用户确认。**

1. **段落大纲**：这段要论证什么判断？推进的步骤是什么？
2. **文献清单**：这段要引用哪些论文？每篇在论证中起什么作用？
3. **文献数量**：和其他段落/路线相比，文献数量是否均衡？
4. **文献关系**：论文之间的真实关系是什么（递进/并列/转折）？

**即使文献清单看似完整，也必须逐条联网验证每篇论文的核心发现、发表期刊和年份。** 本地记忆不可信。

如果有文献缺失或数量不均衡 → 自动触发选文献流程补充。找到候选后，联网验证，再返回向用户确认。

**输出格式必须简洁，用层级缩进：**

```
## 前置检查

> 段落判断：这段要论证什么核心命题

> 判断1：...
>   └ 支撑文献：XX(年份)，具体发现
>   [内部关系：递进/并列/转折]

> 收束：...

**文献清单**：表格

**待确定**：如有
```

用户逐条确认之前，**禁止进入Step 4**。

**Step 4. 从范例找模板。** 在 `examples.md` 中按三层匹配：

1. **关系标签**：搜索 `[转折对立]` `[递进]` `[并列机制]` 等标签。
2. **内容大纲**：对照范例的 `> 内容摘要`，看论证推进方式是否一致。
3. **内部关系**：对照 `[内部关系：XXX]`，确认文献群落组织方式一致。

三层匹配后，提取关联词和句式模板。范例中的段首写法、连接词密度、收束句、概念归属句式参考范例正文即可，不在本文件中重复。

**Step 5. 套模板改文。** 判断先行、文献在括号里做证据。改文完成后，**必须回头对照Step 3的流程图**，确认没有偏离、遗漏、乱序。

**Step 6. 终极检验。** 删掉所有引用和括号，剩文是否逻辑连贯。

**Step 7. 联网验证 + 逻辑检验。**

1. **时间线验证**：列出所有文献的发表年份。如果用了"在此基础上""进一步""由此"等时序关联词，检查年份是否支持先后关系。年份不支持时，改用"围绕""则"等非时序关联词。
2. **联网验证内容**：逐条检索核心发现，确认表述与原文一致。
3. **逻辑链检验**：将段落压缩为短语链（A→B→C→D），看是否有跳跃。

三项通过后，进入Step 8。

**Step 8. 保存 → 进入 hexie-check↔hexie 循环，直到零差距。**

1. 保存为 `原文件名_hexie修改.md`。
2. 调用 hexie-check skill。
3. 有差距 → 修改 → 保存 → 再次 hexie-check。
4. 零差距 → 完成，交还用户。

**硬性检查：每一项修改都必须对照原文，确认未改变原文献的发现含义。**

hexie 改文+正面比对范例，hexie-check 反面找差距。循环终止条件是 hexie-check 零差距。

## 硬性写作规则

范例教不了、必须独立遵守的约束：

**规则1：禁止破折号（——）和冒号（：）。** 句子间的逻辑关系通过语义推进，不借助标点符号。

**规则2：禁止AI腔。** 以下句式直接违规：
- "随着...的发展""在...背景下""近年来...引起了广泛关注"
- "具有重要的理论意义和实践意义"
- "在一定程度上""较为""一定的"
- "鲜有研究探讨""有待进一步研究"
- "一方面...另一方面..."（每节超1次）
- "值得注意的是"

**规则3：引用简洁。** 不写期刊名、国别、数据来源，只写发现。禁止"XX（2020）利用XX数据研究了XX，发现……"

**规则4：禁止元评论。** 不宣告"两条独立传统""这一差异的理论基础来自""争议在于"。直接说内容。两句并列本身就是结构，读者不需要被预告。

## 八种组织方式

完整范例见 `examples.md`。

| # | 方式 | 识别特征 | 范例 |
|---|------|---------|------|
| 1 | 主题线分组 | "与本文相关的第一类文献…第二类文献…" | 严兵(2025)、李宁静(2024)、罗长远(2022)、余振(2024) |
| 2 | 概念论证块 | 每小节一个概念部件，拼起来推假说 | 李雪松(2022)、吴剑峰(2015)、李桂华(2020)、吕铁(2019) |
| 3 | 缺口驱动型 | 累积成果→局限→转移焦点→结构缺口→整合 | 俞荣建(2025)、寇宗来(2023)、郑世林(2025)、王志刚(2025) |
| 4 | 机制推导型 | 以"X通过什么渠道影响Y"为纲 | 刘斌(2023)、罗长远(2022) |
| 5 | 对比型 | 按对立观点组织，指明分歧点和证据 | 李梅(2016)、杨策(2022)、郑世林(2025) |
| 6 | 政策脉络型 | 沿政策演变组织 | 刘斌(2023) |
| 7 | 时间演进型 | 按发展阶段组织 | 柳卸林(2002)、吴晓波(1995) |
| 8 | 概念辨析型 | 围绕概念定义演变组织 | 魏江(1998)、俞荣建(2025) |

## 词语参考（从范例提取，Step 4时对照使用）

**核心原则：元评论和文学化表达必须来自范例。** 通用学术词（促进/抑制/机制/渠道等）不受限制。需要检查的是：告诉读者"接下来要讲什么"的元叙事、过度解释性的比喻（"追问在落点处停下""两个研究岛屿"）、未经时间线验证的时序词（"在此基础上"）。这些词如果在范例中找不到同类用法，替换为范例中的表达。

### 功能词（连接/过渡）

### 功能词（连接/过渡）
| 用途 | 范例用词 |
|------|---------|
| 并列 | 则、另一个维度、与此同时 |
| 转折 | 然而、但、与之相反、与此相对 |
| 递进 | 进一步地、由此、换言之、究其原因 |
| 过渡引导 | 围绕、在此基础上（需验证时间线） |
| 平行条件 | 其一……其二……、一方面……另一方面…… |

### 内容词（名词/动词/形容词）

**报告研究发现（动词）**：指出、发现、表明、揭示、证实、检验

**描述效应方向（动词）**：促进、抑制、驱动、削弱、强化、倒逼

**描述研究动作（动词）**：界定、拆解、追问、检验、考察、嵌入、积累、演化、迭代、识别

**描述研究对象（名词）**：效应、机制、路径、渠道、证据、瓶颈、约束、条件、分歧、空白、差异

**评价性（形容词/副词）**：显著、致命、关键、清晰、一致、突出、尤为

### 句式模板

| 用途 | 范例 |

| 概念归属 | XX最早提出了、将其定义为 |
| 收束否定 | 没有确定结论、并未追问、鲜有研究涉猎 |
| 段落判断 | 相关文献认为、既有研究大多关注 |
| 引出GAP | 但……缺乏深入探究、存在以下不足 |
| 平行条件 | 已有研究识别出至少两类条件。其一……其二…… |
