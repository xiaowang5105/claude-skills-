# 进口贸易自由化是否影响了中国制造业出口技术复杂度

盛 斌 毛其淋\*

内容提要 本文从企业和行业两个层面考察进口贸易自由化与中国制造业出口技术复杂度之间的关系 研究发现，进口贸易自由化显著提高了企业出口技术复杂度，中间品关税减让对企业出口技术复杂度的促进作用大于最终品。 研发创新是进口贸易自由化提升制造业出口技术复杂度的重要渠道，最终品与中间品贸易自由化分别通过 “竞争效应”与 “种类效应”提高企业出口技术复杂度。 此外，行业层面的研究显示，进口贸易自由化对制造业总体出口技术复杂度有显著促进作用，且主要通过资源再配置实现。

关 键 词 进口贸易自由化 出口技术复杂度 种类效应 制造业

## 一 引言

进入新世纪特别是加入世界贸易组织( WTO) 以来，中国在出口贸易上取得了令人瞩目的成就，在2000－2011 年间出口贸易额以年均18.7%的速度快速增长①，目前

已成为世界上最大的出口贸易国 毫无疑问，出口规模的持续快速发展对促进经济增长、提供就业岗位发挥了至关重要的作用。 但在出口数量持续扩张的同时，中国制造业的出口技术复杂度( 或出口竞争力) 究竟经历了怎样的变化，影响因素是什么? 当前研究中国出口竞争力问题具有重要的现实意义: 一方面，受2008 年国际金融危机和欧洲主权债务危机的双重影响，外需疲软已对中国出口数量扩张带来实质性的负面冲击，单纯“以量取胜”的出口模式已难以为继; 另一方面，近些年持续扩大的贸易顺差已使中国面临的贸易摩擦日益增多，严重影响中国出口贸易的进一步发展。 第十二届全国人民代表大会第二次会议政府工作报告中明确提出 “要从战略高度推动出口升级和贸易平衡发展，同时也要实施鼓励进口政策，增加国内短缺产品进口”①; 李克强总理在第十二届全国人民代表大会第五次会议上所做的政府工作报告也明确指出“要增加先进技术、设备和关键零部件进口，促进贸易平衡发展和国内产业加快升级”②。 本研究旨在以中国加入 WTO 所引发的大范围关税减免为背景，深入考察进口贸易自由化对中国制造业出口技术复杂度的影响及其作用机制。

在国际经济学领域，已有不少学者研究了中国出口技术复杂度的变化及其影响因素。 其中，Rodrik(2006) 测算了1999－2001 年中国出口技术复杂度，发现中国出口产品的复杂度远远超过了其经济发展水平，大约与比其人均 GDP 高 3 倍的国家相类似;Schott(2008) 从与OECD 国家出口相似度的视角考察了中国出口商品的技术结构，结果发现中国出口品与 OECD 国家之间的相似度逐年增加; Xu( 2007) 的研究也发现，若以OECD 发达国家为参照，中国出口的相对复杂度水平由1992 年的0.44 上升到2005 年的0.59，这意味着中国的出口结构与竞争力正在逐步升级;邱斌等(2012) 使用世界主要国家的贸易数据进一步计算了中国2001－2009 年制造业2 位码行业的出口技术复杂度，结果表明，绝大多数行业的出口技术复杂度呈上升趋势，即中国制造业的出口竞争力在不断提高。

与上述文献的研究视角不同，另一部分学者关注中国出口技术复杂度的影响因素 例如，Amiti 和 Freund( 2008) 认为中国之所以存在较高的出口技术复杂度主要是由加工贸易导致的; Assche 和 Gangnes( 2010) 在测算出口技术复杂度时剔除了加工贸易的影响，结果发现中国电子产品的出口结构并未出现明显升级 Xu 和 Lu( 2009) 利用2000－2005 年中国海关数据考察了外商直接投资与出口技术复杂度之间的关系，研究认为，来自发达国家的外资比重提高显著促进了中国产业的出口技术复杂度提升。

王永进等( 2010) 基于企业异质性分析框架，从理论上探讨了基础设施影响出口技术复杂度的作用机制，并利用跨国数据进行经验检验，结果表明，基础设施显著促进了出口技术复杂度的提升。 戴翔和金碚( 2014) 利用1996－2010 年跨国面板数据深入考察了产品内分工 制度质量与出口技术复杂度之间的关系，结果表明，制度质量显著促进了出口技术复杂度的提升，并且制度质量越高的地区，产品内国际分工对出口技术复杂度的促进作用越大。 李惠娟和蔡伟宏( 2016) 专门研究了离岸生产性服务中间投入与制造业出口技术复杂度之间的关系，他们利用1995－2011 年行业层面面板数据进行经验检验发现，离岸生产性服务中间投入显著提升了不同技术密集度制造业的出口技术复杂度。 除此之外，还有一些学者研究了出口技术复杂度对中国经济发展的影响。其中，Jarreau 和 Poncet( 2012) 利用中国 1997－2009 年省级面板数据考察了出口技术复杂度与经济增长之间的关系，研究表明，出口技术复杂度有利于促进地区经济增长率的提升。 Poncet 和 Waldemar( 2013) 基于中国城市面板数据的一项经验研究也发现，出口技术复杂度对经济增长具有显著促进作用。 进一步的，李小平等( 2015) 利用中国1998－2011 年行业层面数据检验了制造业出口技术复杂度对行业增长的影响，结果显示，制造业出口技术复杂度的提升显著促进了行业增长，其中重工业、同质性行业和中等技术行业的增长受制造业出口技术复杂度的积极影响更为显著。 尽管已有不少文献就中国出口技术复杂度问题展开了研究，但其共同特点是都以行业或地区层面数据为对象，进而可能掩盖了企业在出口技术复杂度上的异质性。 更为重要的是，上述研究在考察出口技术复杂度的影响因素时，都忽略了中国在2001 年年底加入WTO 后进口贸易自由化不断推进的事实，因此难以全面揭示中国出口技术复杂度演变的真正动因。

本文可能在以下几点推动了现有文献的进展: 第一，已有文献基本上是从行业或地区等宏观层面测算出口技术复杂度，与此不同的是，本文基于中国大样本微观数据，采用 Hausmann 等( 2007) 与 Xu( 2007) 的方法在企业层面进行测算，从而有助于更深入地揭示中国制造业企业出口技术复杂度的演变特征。 第二，现有关于出口技术复杂度问题的研究特别是针对中国的研究还尚未从贸易政策变化的视角进行探讨，本文则以中国加入 WTO 所引发的大范围关税减免为背景，首次分析了进口贸易自由化对中国制造业出口技术复杂度的影响。 此外，本文还深入检验了进口贸易自由化影响制造业出口技术复杂度的作用渠道。 第三，在数据上，与绝大多数文献在国家或行业层面上研究出口技术复杂度问题不同，本文利用2000－2006 年中国工业企业数据和海关贸易数据从企业和行业两个层面进行经验研究，充分考虑了企业出口技术复杂度存在异质性的事实。 另外，本文还按照贸易方式、进口状态和所有权属性将企业划分为不同

## 二 指标测度

## ( 一) 企业出口技术复杂度的测度

本文对 Hausmann 等( 2007) 的方法进行拓展，利用中国大样本微观数据在企业层面对出口技术复杂度进行测算分析。 首先，我们计算某一产品k 的技术复杂度:

$$
P R O D Y _ {k} = \sum_ {c} \frac {\left(x _ {c k} / X _ {c}\right)}{\sum_ {c} \left(x _ {c k} / X _ {c}\right)} \cdot p c g d p _ {c} \tag {1}
$$

其中，k 表示一种 HS6 位码产品，c 表示一个国家或地区， $x _ { c k }$ 表示国家或地区 c 产品 k 的出口额， $X _ { c }$ 表示国家或地区 c 的总出口额。 $x _ { c k } / X _ { c }$ 表示国家或地区 c 产品 k 的出口份额， $p c g d p _ { c }$ 表示国家或地区 c 的实际人均 GDP。 实际上，权重 $(  x _ { c k } / X _ { c } )  / \sum _ { c } (  x _ { c k } /$ $X _ { c } )$ 表示国家或地区 c 在产品 k 出口方面的显示性比较优势。 与既有文献从宏观层面测算出口技术复杂度不同的是，我们利用2000－2006 年中国海关贸易数据库，首次在企业层面对出口技术复杂度进行测算 中国海关贸易数据库上详细报告了企业在HS8 位码产品上每一笔交易的信息，因此，我们需要将企业 HS8 位码产品的出口加总至相应的 HS6 位码产品上，然后采用下式计算企业出口技术复杂度:

$$
E S I _ {i} ^ {n o n} = \sum_ {k} \left(\frac {x _ {i k}}{X _ {i}}\right) \cdot P R O D Y _ {k} \tag {2}
$$

其中， $x _ { i k }$ 表示企业 i 在产品 k 上的出口额， $X _ { i }$ 表示企业 i 的总出口额，相应地， $x _ { i k } /$ $X _ { i }$ 表示企业 i 产品 k 的出口占企业 i 总出口的比重。 尽管 Hausmann 等( 2007) 的方法在测算出口技术复杂度时得到了广泛应用，但是该方法没有考虑出口品在质量方面可能存在的差异性( Xu，2007) 。 即使在较为细化的 HS6 位码产品分类( category) 内，出口品的质量仍有可能存在较大差异，假如一国或地区所出口的商品是 HS6 位码分类中相对低质量的种类( variety) ，那么 Hausmann 等( 2007) 的方法会高估该国或地区的整体出口技术复杂度水平。

为稳健起见，我们借鉴了Xu( 2007) 的方法，在计算产品技术复杂度时根据质量不同进行了相应的调整①。 其步骤为: 首先，采用产品的单位价值来衡量该产品的质量水平: $q _ { c k } = p r i c e _ { c k } / \sum _ { n } ( \mu _ { n k } \cdot p r i c e _ { n k } )$ 。 其中， $p r i c e _ { c k }$ 表示国家或地区 $c \stackrel { \triangledown } { \vec { J } ^ { \mu } }$ 品 k 的出口价格， $, \mu _ { n k }$ 表示国家 n 产品 k 的出口占世界上产品 k 总出口的比重。 因此， $q _ { c k }$ 衡量了国家或地区 c 产品 k 出口的相对价格，若该指数越大，则表明出口产品的质量越高。 我们利用相对价格指数对产品技术复杂度水平进行调整，得到经质量调整的产品技术复杂度为: $P R O D Y _ { k } ^ { a d j } = ( \ q _ { c k } ) \ ^ { \lambda } \bullet \ P R O D Y _ { k }$ ，沿袭 Xu( 2007) 与王永进等( 2010) 的做法将 λ 设定为0. 2。 在此基础上可进一步测算质量调整后的企业层面出口技术复杂度:

$$
E S I _ {i} ^ {a d j} = \sum_ {k} \left(\frac {x _ {i k}}{X _ {i}}\right) \cdot P R O D Y _ {k} ^ {a d j} \tag {3}
$$

在企业出口技术复杂度的测算过程中，主要涉及两组高度细分的产品层面贸易数据。 一组是2000－2006 年171 个国家 HS6 位码产品的出口数据，来自联合国统计司的 Comtrade 贸易数据库，另一组是2000－2006 年的中国海关贸易数据库 此外，国家或地区的人均实际 GDP 数据来自世界银行 WDI 数据库。

表1 展示了不同类型企业的出口技术复杂度的变化趋势。 首先，从贸易方式来看，加工贸易企业的出口技术复杂度要明显地高于一般贸易企业 例如，在 2000－2006 年期间，加工贸易企业与一般贸易企业的出口技术复杂度均值分别约为202 千美元和 113 千美元，前者显著高于后者，这同 Amiti 和 Freund( 2008) 与 Assche 和 Gangnes( 2010) 的结论类似，即加工贸易企业具有更高的出口技术复杂度。 不过随着时间的推移，两种类型企业的出口技术复杂度都在整体上呈上升趋势，并且一般贸易企业的升幅相对更大，导致两种类型企业出口技术复杂度之间的差距不断缩小，其均值差异值从2000 年的98 千美元缩小至2006 年的88 千美元

其次，按照企业是否进口将样本区分为进口企业与非进口企业进行比较分析，统计结果显示，进口企业比非进口企业具有更高的出口技术复杂度，其均值差异都在1%水平上显著; 从时间维度上看，进口企业与非进口企业的出口技术复杂度都整体有不同幅度的增长。

最后，我们还根据企业所有权属性，进一步比较了外资企业与本土企业的出口技术复杂度。 从中可以看出，与本土企业相比，外资企业具有更高的出口技术复杂度，这便印证了 Branstetter 和 Lardy( 2006) 与 Xu 和 $\mathrm { L u }$ ( 2009) 的观点，即外商直接投资有助于提高中国出口技术复杂度并改善出口竞争力 此外，我们还发现，随着时间推移，本土企业与外资企业出口技术复杂度的差距在不断缩小，这意味着本土企业的出口技术复杂度获得了相对更快的增长。

## ( 二) 进口贸易自由化的测度

通过上述分析可以看到，自2000 年以来，中国制造业企业的出口技术复杂度显著提高 同时也应注意到，中国在此期间加入了 WTO，进口贸易自由化进程不断推进我们通过构造进口贸易自由化指标来具体呈现 2000－2006 年期间中国制造业进口贸易自由化水平的演变趋势。 本文根据现有文献的普遍做法( Amiti 和 Konings，2007;Ahsan 和 Mitra，2014) ，采用最终品关税率来衡量贸易自由化:

$$
\tau_ {j t} ^ {O} = \sum_ {k \in I n d _ {j}} \text {num} _ {k t} \cdot \text {importtariff} _ {k t} / \sum_ {k \in I n d _ {j}} \text {num} _ {k t} \tag {4}
$$

其中 $, j$ 和 t 分别表示行业和年份，k 表示 HS6 位码产品， $I n d _ { j }$ 表示行业 j 的产品集合， $n u m _ { k t }$ 表示第t 年HS6 位码产品k 的税目数， $i m p o r t t a r i f f _ { k t }$ 表示第t 年HS6 位码产品k的进口关税税率。 此外，本文还进一步考虑了中间品关税来刻画进口贸易自由化水平。 中间品关税的测算借鉴 Schor( 2004) 的做法，将其定义为:

$$
\tau_ {j t} ^ {I} = \sum_ {w \in \Theta_ {j}} \theta_ {w t} \cdot \tau_ {w t} ^ {O} \tag {5}
$$

其中， $\theta _ { j }$ 表示行业 j 的投入集合， $\theta _ { w t } = I n p u t _ { w t } / \sum _ { w \in \Theta _ { i } } I n p u t _ { w t }$ t表示要素 w 的投入权重，用投入要素 $w$ 的成本占行业 j 总投入要素成本的比重来衡量①， $\boldsymbol { \tau } _ { w t } ^ { o }$ 表示要素 w 在 t期的最终品关税。

## 三 计量模型 变量与数据

## ( 一) 基准计量模型与变量

为考察进口贸易自由化对企业出口技术复杂度的影响，本文基准计量模型为:

$$
\ln E S I _ {i t} = \alpha_ {0} + \alpha_ {1} \tau_ {j t} ^ {O} + \alpha_ {2} \tau_ {j t} ^ {I} + \beta X _ {i j t} + v _ {i} + v _ {t} + \varepsilon_ {i j t} \tag {6}
$$

其中，下标 i 表示企业 $, j$ 表示行业，t 表示年份。 被解释变量 ln ESI 为企业出口技术复杂度的对数值，最终品关税( $\tau _ { j t } ^ { o } )$ 与中间品关税( $\tau _ { j t } ^ { I } )$ 是本文核心解释变量，分别用以刻画最终品贸易自由化和中间品贸易自由化水平，测算方法见前文。 $v _ { i }$ 和 $v _ { t }$ 分别表示企业和年份固定效应， $\varepsilon _ { i j t }$ 为随机扰动项。

对控制变量 $X _ { i j t }$ 的设定和说明如下:(1) TFP 表示企业生产率，这里采用 Olley 和 $\mathrm { P a } -$ kes(1996) 的方法估算得到，即使用投资作为企业受到生产率冲击时的调整变量①。( 2) herfindahl表示赫芬达尔指数，其计算式 为 $\begin{array} { r } { \left. h e r f i n d a h l _ { j t } \right. = \sum _ { i \in I n d _ { j } } \left( \ s a l e _ { i t } / s a l e _ { j t } \right) ^ { \mathrm { ~ 2 ~ } } = } \end{array}$ $\textstyle \sum _ { i \in I n d _ { j } } S _ { i t } ^ { 2 }$ ，其中 $\mathit { s a l e } _ { i t }$ 表示企业 i 在 t 年的销售额， $s a l e _ { j t }$ 表示行业 j 在 t 年的总销售额， $S _ { i t }$ 表示企业 i 在 t 年的市场占有率。 如果该指数越大则表明行业市场集中程度越大，即垄断程度越高 ( 3) klratio 表示资本密集度，用固定资产净值年平均余额与从业人员年平均人数的比值取对数来衡量，其中固定资产净值年平均余额使用以 2000 年为基期的固定资产投资价格指数进行平减处理 ( 4) medium 和 large 分别表示中型和大型企业虚拟变量。 我们将企业按其销售额从小到大划分为 3 等份，分别定义为小型 中型和大型企业，当企业i 属于中型企业时，medium 取值为1，否则为0; 类似地，当企业i属于大型企业时，large 取值为1，否则为 $0 _ { \circ }$ ( 5) age 表示企业年龄，用当年年份与企业开业年份的差来衡量。 ( 6) soes 和 foreign 分别表示国有企业和外资企业虚拟变量。预期国有企业出口技术复杂度较低，而外资企业较高。 ( 7) subsidy 表示政府补贴，用政府补贴与企业销售额的比值取对数来衡量 ( 8) finance 表示融资约束，我们借鉴孙灵燕和李荣林( 2011) 的做法，采用利息支出与固定资产的比值取对数进行衡量，该值越大，表明企业面临的融资约束问题越小。

## ( 二) 数据

本研究使用的数据主要有: 产品层面的进口关税数据 中国工业企业数据库以及中国海关贸易数据。 其中，产品层面的进口关税数据来自 WTO 的 Tariff Download Fa-cility 数据库与世界银行的 WITS 数据库。 中国工业企业数据来自国家统计局，时间跨度为2000－2006 年，其统计调查的对象涵盖了全部国有工业企业以及 “规模以上”( 主营业务收入大于500 万元) 非国有企业 海关贸易数据来自中国海关总署，时间跨度为2000－2006 年，它记录了各个月度通关企业的每一笔产品层面( HS8 位码) 的交易信息。 为研究需要，我们将月度数据加总为年度数据。

本研究的一个重要工作是将中国工业企业数据库与海关贸易数据库进行合并由于中国工业企业数据库中的企业代码与海关贸易数据库中的企业代码采用的是两套编码系统①，不能直接根据企业代码将两套数据库进行合并，因此我们借鉴 Yu( 2015) 的方法对这两套数据库进行合并。 鉴于本文的研究重心是考察进口贸易自由化对企业出口技术复杂度的影响，因此我们选取以上两个数据库中可以被合并的出口企业作为分析样本。 除此之外，我们还对样本数据进行如下处理。 第一，中国在2002年颁布了新的 《国民经济行业分类》并于 2003 年开始正式实施，为统一口径，我们依照新的行业标准对2000－2002 年企业的行业代码进行了重新调整。 第二，由于原始数据的一些关键性指标在统计上存在缺漏值或错误记录，我们对数据进行以下筛选:( 1) 删除出口额存在缺漏值或负值的企业样本; ( 2) 删除雇员人数小于 10 的企业样本; ( 3) 删除工业增加值 中间投入额 从业人员年平均人数 固定资产净值年平均余额中任何一项存在缺漏值、零值或负值的企业样本; ( 4) 删除1949 年之前成立的企业样本，同时删除企业年龄小于0 的企业样本

## ( 二) 影响渠道检验①

前文发现进口贸易自由化显著提高了企业出口技术复杂度，很自然的我们会进一步考虑，为什么进口贸易自由化会提高企业的出口技术复杂度，其背后可能的影响渠道是什么? 回答这一问题有助于更好地理解近年来中国制造业企业出口技术复杂度变迁的动因。

大量研究已经证实进口贸易自由化对企业创新具有积极的促进作用( Teshima，2009; 田巍 和 余 淼 杰，2014; 赵 建 春 和 毛 其 淋，2015; Liu 和 Qiu，2016; Tian 和 Yu，2017) ，而企业创新是决定出口技术复杂度变动的重要因素( 郭晶和杨艳，2010; Zhu 和Fu，2013; 亢梅玲和王靖慧，2014) 。 据此，我们可以很自然地推测，企业创新可能是进口贸易自由化影响企业出口技术复杂度的一个渠道。 为验证这一推测，我们将进口贸易自由化变量与企业创新变量的交叉项纳入模型中进行估计。 首先，我们从创新投入的角度来衡量企业创新，使用企业研发的自然对数②来衡量企业创新( Innov) 。 在表3第( 1) 列回归中，我们加入了最终品关税与企业研发的交叉项 $\tau ^ { o } \times I n n o v )$ ，其估计系数在5%水平下显著为负，说明研发投入越大的企业最终品贸易自由化对其出口技术复杂度的促进作用越大，这就意味着，最终品关税减让的确是通过促进企业研发的途径作用于企业出口技术复杂度的 在表3 第( 2) 列回归中，我们加入了中间品关税与企业研发的交叉项( $\tau ^ { I } \times I n n o v )$ ，得到其估计系数也显著为负，说明研发投入越大的企业，中间品关税减让对其出口技术复杂度的促进作用就越大，中间品贸易自由化对企业出口技术复杂度的影响也是通过促进企业研发渠道产生作用的。 此外，我们还将以上两个交叉项同时纳入模型中，回归结果见表 3 第( 3) 列。 从中可以看到，交叉项$\tau ^ { o } \times I n n o v$ 与 $\tau ^ { I } \times I n n o v$ 仍显著为负，且与表 2 第( 6) 列未引入任何交叉项的基准估计结果相比，最终品关税 $( \mathbf { \nabla } _ { \tau } { } ^ { o } )$ 与中间品关税 $( \triangledown _ { \tau } { } ^ { I } )$ 的估计系数绝对值明显下降，这进一步说明，进口贸易自由化对企业出口技术复杂度的促进作用是通过企业研发起作用的。

为稳健起见，我们进一步从创新产出角度来衡量企业创新，使用企业新产品销售额的自然对数来刻画①，表3 第( 4) 列报告了相应的回归结果②。 从中可以看到，两个交叉项 $\tau ^ { o } \times I n n o v$ 与 $\tau ^ { I } \times I n n o v$ 的估计系数均显著为负，再次证明前文结论稳健。

## ( 二) 基于准自然实验的倍差法估计①

考虑到中国加入 WTO 可以看作是一个贸易自由化的外生政策冲击，为稳健起见，我们将中国加入 WTO 作为准自然实验，进而采用倍差法( DID) 来估计进口贸易自由化对制造业出口技术复杂度的影响。 我们借鉴 Lu 和 Yu( 2015) 与 Liu 和 Qiu( 2016) 的做法，构造倍差法模型，分别检验最终品贸易自由化与中间品贸易自由化的

影响效应①:

$$
\ln E S I _ {i t} = \alpha_ {0} + \alpha_ {1} \text {OutTar} _ {j 0 1} \times \text {Post02} _ {t} + \alpha_ {2} \tau_ {j t} ^ {I} + \varphi \boldsymbol {X} _ {i j t} + v _ {i} + v _ {t} + \varepsilon_ {i j t} \tag {7}
$$

$$
\ln E S I _ {i t} = \beta_ {0} + \beta_ {1} \text {InTar} _ {j 0 1} \times \text {Post02} _ {t} + \beta_ {2} \tau_ {j t} ^ {o} + \varphi \boldsymbol {X} _ {i j t} + v _ {i} + v _ {t} + \varepsilon_ {i j t} \tag {8}
$$

其中， $O u t T a r _ { j 0 1 }$ 表示行业 j 在 2001 年的最终品关税率， $I n T a r _ { j 0 1 }$ 表示行业 j 在 2001年的中间品关税率; Post02 为中国入世时间虚拟变量，若是 2002 年及其之后的年份取值为1，否则取值为0; 除此之外，其余变量的定义与( 6) 式相同。 在( 7) 式中，交叉项 $O u t T a r _ { j 0 1 } \times P o s t 0 2 _ { \scriptscriptstyle { \perp } }$ t 是我们最为关注的，若 $\alpha _ { 1 }$ 显著为正，表明最终品贸易自由化提高了出口技术复杂度; 同理，在( 8) 式中，我们最感兴趣的是 $\beta _ { 1 }$ ，若 $\beta _ { 1 }$ 显著为正，则表明中间品贸易自由化促进了出口技术复杂度的提升，反之则相反。 表5 第( 2) 和( 3) 列分别报告了对( 7) 和( 8) 式的 DID 估计结果。 从中可以看到，交叉项 $O u t T a r _ { 0 1 } \times P o s t 0 2$ 与 $I n T a r _ { 0 1 } \times P o s t 0 2$ 的估计系数均显著为正，这再次表明进口贸易自由化对企业出口技术复杂度的提升起到了显著促进作用。 进一步的比较发现，交叉项 $I n T a r _ { 0 1 } \times P o s t 0 2$ 的估计系数要大于交叉项 $O u t T a r _ { 0 1 } \times P o s t 0 2$ 的估计系数，意味着中间品贸易自由化对企业出口技术复杂度的提升作用大于最终品贸易自由化。

## ( 三) 样本选择性偏差

现实中并不是所有企业都进行出口，如果企业是否进行出口不是随机分布，那么直接对出口企业样本进行估计将可能存在样本选择性偏差。 我们采用 Heck-man( 1979) 两步法对样本选择偏差进行处理 。 Heckman( 1979) 两步法第一阶段与第二阶段的估计结果分别报告在表5 第( 4) 和( 5) 列。 从第一阶段估计结果来看，最终品关税与中间品关税的估计系数均显著为负，表明进口贸易自由化促进了企业的出口参与，这与 Bas( 2012) 对阿根廷、毛其淋和盛斌( 2013) 对中国的研究结论一致。 从第二阶段的估计结果来看，逆米尔斯比率 Millsratio 的估计系数显著为正，说明样本中确实存在一定的选择性偏差。 不过核心解释变量最终品关税与中间品关税的估计系数符号和显著性水平没有变化，而且它们的系数大小与表 3 第( 2) 列的估计结果较为接近。 由此可见，尽管样本中存在一定的选择性偏差，但并未对本文的核心结论产生实质性影响，即再次表明，最终品贸易自由化与中间品贸易自由化对企业出口技术复杂度的提升均具有促进作用，并且后者的影响程度更 大 。

## ( 四) 企业出口技术复杂度的其他测算方法

在前文，我们主要采用Hausmann 等(2007) 的方法测算企业出口技术复杂度 尽管这一方法在相关研究中得到了广泛运用，但它与国家收入水平联系紧密，在实际使用中容易导致“富国出口复杂产品，穷国出口简单产品; 复杂产品由富国出口，简单产品由穷国出口”的循环结论( 李小平等，2015) 。 为稳健起见，我们采用 Hausmann 和 Hidalgo( 2010) 的方法①重新测算出口技术复杂度。 首先，我们借鉴 Hausmann 和 Hidalgo( 2010)的方法测算产品层面的技术复杂度( 用 $P R O D Y _ { k } ^ { H H }$ 表示) ，然后以产品 k 出口占企业 i 总出口的比重为权重，对产品层面的技术复杂度进行加权平均，进而得到新的企业出口技术复杂度指标 $E S I _ { i } ^ { H H }$ 。 以 $\mathrm { ~ l n ~ } E S I _ { i } ^ { H H }$ 为因变量的估计结果报告在表5 第( 6) 列，结果显示，最终品关税与中间品关税的估计系数依然显著为负，再次说明进口贸易自由化显著促进了企业出口技术复杂度的提升，并且中间品贸易自由化的作用大于最终品关税减免。 由此可见，这一核心结论并不随企业出口技术复杂度测算方法的改变而发生变化。

## ( 五) 进口贸易自由化的其他度量指标

在前文的回归中，我们均采用进口关税率来衡量进口贸易自由化，但进口贸易自由化的范围还涉及非关税壁垒及其他一些制度性因素，有鉴于此，本文进一步采用进口渗透率( 用 Importpen 表示) 作为进口贸易自由化的度量指标来进行稳健性检验 测算进口渗透率所用的 HS6 位码进口数据来自 Comtrade 贸易数据库，为了得到行业水平上的进口贸易额，我们需做以下几方面工作: 第一步，由于 Comtrade 贸易数据库上所载的进口数据共有 HS1996 和 HS2002 两个版本②，我们根据联合国统计司提供的HS1996 和 HS2002 之间的转换表将 2000－2001 年进口统计口径统一为 HS2002 版本; 第二步，根据 HS2002 与 GB/T2002 之间的转换关系，将 HS6 位码进口加总至 GB/T2002 的2 位码行业水平，并且用相应年份的人民币兑美元汇率的中间价折合成以人民币为单位，得到 $\sum _ { i } i m p o r t _ { i j }$ ，同时也将企业 i 的产出 $\ o u t p u t _ { i }$ 和出口额 $e x p o r t _ { i }$ 分别加总至 GB/T2002 的 2 位码行业水平，得到 $\sum _ { i } o u t p u t _ { i j }$ 和 $\sum _ { i } e x p o r t _ { i j }$ 。 接下来，根据 Ekholm 等( 2012) 的做法，把行业 j 的进口渗透率表示为 Importpenj = i ij∑ ioutputij + ∑ iimportij － ∑ iexportij $I m p o r t p e n _ { j } = \frac { \sum _ { i } i m p o r t _ { i j } } { \sum _ { i } o u t p u t _ { i j } + \sum _ { i } i m p o r t _ { i j } - \sum _ { i } e x p o r t _ { i j } } ,$ 。 本文使用进口渗透率衡量进口贸易自由化的估计结果报告在表5 第( 7) 列。 结果显示，进口渗透率的估计系数为正并在1%水平下显著，表明在综合考虑了进口关税和非关税壁垒后，进口贸易自由化显著促进了企业出口技术复杂度的提高

此外，我们还在最终品关税率与中间品关税率的基础之上进一步计算了行业的有效保护率( Effective Rate of Protection，ERP) ，其计算方法为:

$$
E R P _ {j t} = \left(\tau_ {j t} ^ {O} - \tau_ {j t} ^ {I}\right) / \left(1 - \sum_ {w \in \Theta_ {j}} \theta_ {w t}\right) \tag {9}
$$

有效保护率刻画了关税对中间投入品和最终品保护的净效应，这里我们用它作为进口贸易自由化新的衡量指标，估计结果报告在表 5 第( 8) 列 从中可以看到，有效保护率( ERP) 的估计系数显著为负，表明贸易保护净效应的降低显著促进了企业出口技术复杂度的提高。 因此，进口贸易自由化提高企业出口技术复杂度这一主要结论不会因进口贸易自由化度量方法的不同而改变，具有较好的稳健性。

## 六 分析拓展:进口贸易自由化、资源再配置与行业出口复杂度

前文从微观层面考察了进口贸易自由化对企业出口技术复杂度的影响效应，接下来我们进一步从宏观层面研究进口贸易自由化与制造业行业出口技术复杂度之间的关系，以及考察资源再配置在其中扮演的作用 我们按照下式计算行业总体的出口技术复杂度:

$$
\ln E S I _ {j t} ^ {A G G} = \sum_ {i \in I n d _ {j}} \theta_ {i t} \cdot \ln E S I _ {i t} \tag {10}
$$

其中，下标 i 表示企业 j 表示行业 t 表示时间， $I n d _ { j }$ 表示行业 j 的企业集合。$\ln { \cal E S } I _ { j t } ^ { A G G }$ 表示以行业 j 内所有企业的出口份额为权重进行加权得到的行业总体出口技术复杂度; $\theta _ { i t }$ 是权重系数，以企业 i 在行业 j 中的出口份额来衡量。 借鉴 Olley 和 Pakes( 1996) 对生产率的分解方法，构造如下分解恒等式:

$$
\begin{array}{l} \ln E S I _ {j t} ^ {A G G} = \overline {{\ln E S I _ {j t}}} + \sum_ {i \in I n d _ {j}} \left(\theta_ {i t} - \bar {\theta} _ {j t}\right) \left(\ln E S I _ {i t} - \overline {{\ln E S I _ {j t}}}\right) \\ = \overline {{\ln E S I _ {j t}}} + \sum_ {i \in I n d _ {j}} \Delta \theta_ {i t} \Delta \ln E S I _ {i t} \tag {11} \\ \end{array}
$$

其中， $\overline { { \theta } } _ { j t }$ 表示行业 j 内所有企业的平均出口份额; $\mathrm { ~ l n ~ } E S I _ { i t }$ 为企业 i 的出口技术复杂度， $\mathrm { ~ l n ~ } E S I _ { j t }$ 表示行业 j 内所有企业的简单平均出口技术复杂度。 ( 11) 式右边第一项为非加权平均出口技术复杂度，记为 $\mathrm { ~ l n ~ } E S I _ { j t } ^ { A V E }$ ; 右边第二项为企业出口技术复杂度与出口份额的协方差，记为 $\ln { \cal E S } I _ { j t } ^ { R E L }$ ，它衡量了出口份额在具有不同出口技术复杂度( 或出口竞争力水平) 企业之间的再配置效应，其含义为: 如果该项越大，则表明出口技术复

## 七 结论

本文利用2000－2006 年中国工业企业数据和海关贸易数据，从企业和行业层面考察了进口贸易自由化与制造业出口技术复杂度之间的关系 归纳起来，本文主要得到如下研究结论: 第一，进口贸易自由化显著提高了中国制造业企业的出口技术复杂度，其中中间品关税减让对企业出口技术复杂度的促进作用大于最终品关税减让，这一结论在处理潜在的内生性问题与样本选择性偏差问题进行倍差法估计时，选择企业出口技术复杂度和进口贸易自由化的其他衡量指标以及剔除贸易中间商的样本之后依然

稳健。 第二，从影响机制上看，研发创新是进口贸易自由化提升制造业出口技术复杂度的重要渠道。 此外，最终品与中间品贸易自由化还分别通过 “竞争效应”与 “种类效应”提高企业出口技术复杂度。 第三，从分组检验来看，进口贸易自由化( 尤其是中间品关税减让) 对一般贸易企业、进口企业和本土企业出口技术复杂度的提升作用分别大于加工贸易企业、非进口企业和外资企业。 第四，行业层面研究发现，进口贸易自由化显著促进了行业总体出口技术复杂度的提升，并且主要通过资源再配置的途径实现

本文在一定程度上填补了关于进口贸易自由化与中国制造业出口技术复杂度研究的空白，为理解近年来中国制造业出口技术复杂度的动态演进提供了新视角和经验证据。 除此之外，本研究还具有重要的政策含义。 长期以来，中国施行的是出口导向型贸易发展模式，而进口贸易一直处于从属地位，其作用仍未引起足够重视。 而本文从经验上证实了，进口贸易自由化对于促进制造业出口技术复杂度提升与出口竞争力升级具有重要作用 因此，转变 “重出口轻进口”的传统观念，实施选择性的 “以进口促出口”的政策调整对于提升企业出口竞争力，进而实现中国出口贸易模式由过去的“数量竞争”向“质量竞争”转变显得尤为重要。

# Does Import Trade Liberalization Affect Chinese Manufacturing Export Technological Sophistication?

Sheng Bin; Mao Qilin

Abstract: This paper empirically explores the relationship between import trade liberalization and export technological sophistication of Chinese manufacturing firms. The empirical results show that，import trade liberalization has significantly promoted Chinese manufacturing firms' export technological sophistication. We also find the impact of input tariff reductions on export technological sophistication is larger than that of output tariff reductions. Firm innovation is an important channel of the former effect，as well as the pro-competitive effect for output trade liberalization and variety effect for input trade liberalization. The last but not the least，the import trade liberalization has significant promoting effects in general manufacturing industry，mainly via resources reallocation．

Key words: import trade liberalization，export technological sophistication，variety effect，manufacturing JEL code: F13，F14，O33
