# 05 无标签推进

---

## 技法：无标签推进 / 一句话收束五篇文献，不提关系

**原句**：产业政策效果的文献不可谓少，但目光大多集中于企业融资、环境治理、市场进出、产业升级和投资效率（连立帅等，2015；崔广慧等，2020；周开国等，2018；逯进等，2020；刘慧等，2022），被解释变量始终没有触及供应链韧性。
**来源**：hexie-writer 改写产出
**为什么有效**：五篇文献，一句打包。不写"连立帅研究了……崔广慧发现了……周开国探讨了……"——那些是罗列。这句话的逻辑是：它们共同回避了一个问题。关系（共同回避）靠"但目光大多集中于……始终没有触及"来推送，不需要说"这些研究是并列关系"。
**禁止写法**：连立帅等（2015）研究了信贷资源配置，崔广慧等（2020）关注了企业环境治理，周开国等（2018）分析了企业进退……这些研究从不同角度讨论了产业政策效果，但它们都没有触及供应链韧性。

## 技法：无标签推进 / "不过"推进条件逻辑，不用"然而需要指出的是"

**原句**：不过，政策的力量并非无条件释放。一份关于半导体产业政策与区域生态的系统综述警示，脱离本地创新系统吸收能力的政策干预，可能陷入"执行-情境"错配（Cai et al., 2026）；演化博弈分析也表明，稳定可信的政策环境是政府、核心厂商与海外供应商围绕供应安全形成协同行动的先决条件（Yuan et al., 2026）。
**来源**：hexie-writer 改写产出
**为什么有效**："不过"三字完成从"政策有效"到"政策有条件"的转向。下一句不给声明（"政策有效性受到以下因素制约"），直接给两个具体发现。Cai 和 Yuan 之间的关系靠分号并列推送，不需要"二者从不同角度共同说明"。
**禁止写法**：然而，产业政策的有效性并非绝对，它受到多重因素制约。Cai等（2026）和Yuan等（2026）分别从区域生态和博弈分析的角度提供了证据，二者形成了互补关系。

## 技法：无标签推进 / 三段文献分别引出，用共同判断收束

**原句**：Chen等（2026）发现，新能源汽车推广政策对供应链韧性的提升效应在国有企业和中西部地区企业中更为明显；Lv等（2026）指出，数字化转型对韧性的促进作用在非国有企业、非数字经济行业及大型企业中更强；Zhao等（2026）的fsQCA分析则揭示，知识强度与政府补贴虽是影响韧性的核心条件，企业却需通过"内生组织赋能""环境-组织协同"等差异化路径实现高韧性。这些发现共同指向一个事实：同一政策落在不同企业身上，效果并不均等。
**来源**：hexie-writer 改写产出
**为什么有效**：三篇文献用分号并列推出，不给各自的关系标签。第四句"这些发现共同指向一个事实"完成归纳——这是唯一的"关系声明"，但它不是标签式的（"三者为并列关系"），而是判断式的（"效果并不均等"）。
**可复用模式**：文献A发现；文献B发现；文献C发现。→ 这些发现共同指向一个事实：[归纳判断]。
