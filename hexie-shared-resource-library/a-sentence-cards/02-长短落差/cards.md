# 02 长短落差

---

## 技法：长短落差 / 长铺陈 + 短切断（落差 85 字）

**长句**：但另一方面，从经济理论的角度看，这个奇迹的神秘之处在于其"非常规"的性质：经济增长理论所强调的若干增长条件，如自然资源禀赋、物质和人力资本积累以及技术创新能力，中国与其它国家相比并无独特之处，甚至处于低水平阶段，如人均资源禀赋、技术创新水平。（112字）
**短句**：也就是说，按照这些理论的预言，中国不应该有经济奇迹发生。（27字）
**来源**：周黎安（2007），《经济研究》
**为什么有效**：112 字逐条枚举"中国不应该行"的证据，27 字收束为一个反事实陈述。节奏上先让你跟着证据走，走到底发现结论和直觉完全相反。落差 85 字，但短句不抢戏，稳稳坐在最后。
**可复用模式**：证据枚举（≥100字）→ "也就是说/按此逻辑/照此推演" → 反直觉短判断（≤30字）。

## 技法：长短落差 / 短句切断 + 中长展开（落差 89 字）

**长句**：正因如此，半导体已成为各国产业政策的角力场——美国《芯片与科学法案》以巨额补贴和税收减免吸引产能回流（Gupta and Sharma, 2024），欧盟以"技术主权"为由强化本土供应（Farrand, 2025），中国、日本、韩国也在持续加码国家支持（Liu et al., 2024; Park, 2023; Lee, 2024）。（100字）
**短句**：这一问题在半导体产业尤为紧迫。（14字）
**来源**：hexie-writer 改写产出
**为什么有效**：短句领头，给方向；长句紧跟，给证据。落差 86 字，短句的作用是把读者注意力从"产业政策大背景"拽到"半导体"这个焦点上。
**可复用模式**：短焦点句（≤20字）→ 长证据句（≥80字）→ 判断收束。

## 技法：长短落差 / 极短转折 + 中长证据（落差 125 字）

**长句**：Chen等（2026）发现，新能源汽车推广政策对供应链韧性的提升效应在国有企业和中西部地区企业中更为明显；Lv等（2026）指出，数字化转型对韧性的促进作用在非国有企业、非数字经济行业及大型企业中更强；Zhao等（2026）的fsQCA分析则揭示，知识强度与政府补贴虽是影响韧性的核心条件，企业却需通过"内生组织赋能""环境-组织协同"等差异化路径实现高韧性。（133字）
**短句**：事实显然并非如此。（8字）
**来源**：hexie-writer 改写产出
**为什么有效**：短到极致的判断句切断前文的理论假设，落差 125 字，制造了全文最大的节奏跳跃。"事实"二字直接对冲"假设"，不绕弯。
**可复用模式**：假设句 → "事实显然并非如此。"（8字切断）→ 并列证据展开。
