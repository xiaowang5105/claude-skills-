# 03 关联词位置

---

## 技法：关联词位置 / "不过"藏于句中

**原句**：对德国半导体企业的实地调研表明，政府补贴、供应风险意识与地缘政治压力正共同构成驱动企业投资决策的三个关键支点（Raj and Wuttke, 2026）。与关税等强制性工具相比，围绕财政激励展开的产业政策在引导产能布局和供应链分散化方面更为奏效（Peng, 2025）。不过，政策的力量并非无条件释放。
**来源**：hexie-writer 改写产出
**为什么有效**：前两句递进并列（正面证据），"不过"孤悬一句，15 字，不带任何引用。转折后不给证据——先给判断，下一句才展开 Cai 和 Yuan 的证据。关联词本身也充当了长短落差中的"短句"。
**可复用模式**：并列正面证据（2 句）→ "不过，[判断]。"（短句，无引用）→ 条件/警示证据展开。

## 技法：关联词位置 / "然而"位于长句之首

**原句**：然而，这些重要文献的大量问世愈加彰显出中国的经济增长作为一种奇迹的意义。
**来源**：周黎安（2007），《经济研究》
**为什么有效**：前段全部在讨论制度对增长的重要性（North, Acemoglu 等），"然而"一出现，整个论证方向转了——不是否定前面的文献，而是说它们越正确，中国就越显得反常。关联词承担的不是"反对"，是"升级"。
**可复用模式**：援引主流理论 → "然而，[理论越成立 → 事实越反常]"。

## 技法：关联词位置 / 不用关联词，两句对峙

**原句**：这些发现共同指向一个事实：同一政策落在不同企业身上，效果并不均等。然而，现有研究多停留在描述"什么条件下效果更强"，缺乏从企业内部能力角度的统一解释。
**来源**：hexie-writer 改写产出
**为什么有效**：前句总结三篇文献的共性发现，"然而"带出缺口——但注意"然而"前后是两套完整的判断。"共同指向一个事实"本身已经是一个收束句，"然而"后接的不是新证据，而是更上层的缺口诊断。
**可复用模式**：证据总结句 → "然而，[研究多停留在……，缺乏……]" → 本文进入。

## 技法：关联词位置 / "与此同时"升维

**原句**：与此同时，半导体供应已被纳入更高阶的战略框架。
**来源**：hexie-writer 改写产出
**为什么有效**：前段收束在"精准嵌合"，此句不从嵌合继续推——而是跳出原来的论证层，进入更高的战略维度。"与此同时"在这里不是并列，是升维：前面说的是产业层面，这里说的是安全层面。
**可复用模式**：[产业层面收束] → "与此同时，……已被纳入更高阶的战略框架。" → 战略维度展开。
