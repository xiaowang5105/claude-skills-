# hexie 素材质量分层索引

本索引用于指导 `hexie-writer` 和 `hexie-check` 读取素材。核心原则是“写法类型 × 素材质量”二维判断：

- 写法类型回答：这份材料属于哪一种开篇组织方式。
- 素材质量回答：AI 可以安全学到什么程度。

目录名和写法类型都不是质量等级。A/B/C 只表示当前这份文本的可复用强度，不表示这种写法本身高级或低级，也不代表材料的学术价值高低。

## 二维判断规则

先判断写法类型，再判断素材质量：

1. 写法类型：主题线分组、概念论证块、缺口驱动、机制推导、对比型、政策脉络、时间演进、概念辨析。
2. 素材质量：A、B、C。
3. 使用方式：同一种写法可以同时存在 A/B/C 不同质量素材；writer/check 不得因为某个当前文件是 B 或 C，就否定这种写法本身。
4. 事实边界：无论 A/B/C，都不能作为当前论文的现实背景事实或文献事实依据。

## A/B/C 定义

| 层级 | 名称 | 可用于 | 不可用于 |
|------|------|--------|----------|
| A | 完整结构模板 | 文本干净、段落完整、结构清楚、标注明确时，可学习整段结构、问题链、文献群落组织、贡献定位、句层节奏和收束方式。 | 当前论文事实依据；照搬原文；替代引用核验。 |
| B | 去事实后结构模板 | 文本有用但不够干净时，删除或忽略作者、年份、政策、数据、案例、具体结论和引用事实后，只学习判断链、句群推进、转折方式和收束方式。 | 引用事实、背景事实、整段原样模仿、具体机制方向、具体政策判断。 |
| C | 词感语料 | OCR 污染重、结构断裂、年份较旧、混入正文其他部分或不可稳定抽取结构时，只搜索 1-3 段相近表达，参考词语、短语、连接方式和中文经管论文气口。 | 结构模板、引用事实、背景事实、标点格式、引用格式、段落骨架。 |

简单说：

```text
A = 学完整结构
B = 去事实/引用后学结构骨架
C = 只学词语和气口
```

## 默认读取顺序

1. 先判断任务类型：引言、文献综述、理论铺垫、现实背景、研究缺口、贡献段。
2. 再判断适合的写法类型：八种组织方式中哪一种或哪几种最匹配。
3. 在对应写法类型下查找素材等级：优先 A；没有 A 时使用 B；C 只用于语言风格。
4. 使用 B 时，必须先删除或忽略作者、年份、政策、数据、案例、具体结论和引用事实，只学习剩余判断链、句群推进、转折方式和收束方式。
5. 使用 C 时，只能关键词搜索，每次最多取 1-3 段相近语料，用于去 AI 腔和中文经管论文气口。
6. 所有政策、年份、事件、数据、企业案例、制度背景、国际形势和文献发现，都必须回到用户材料、原文、PDF、MD 或可靠来源核验。

## 新增素材快速判断流程

新增素材时按以下顺序判断：

1. 是否有严重 OCR 污染、断句错乱、空括号、残缺英文、页眉页脚混入？如果是，判 C。
2. 是否不是完整开篇段落，只是零散句子、表格、摘要、方法、实证、结论或政策建议？如果是，判 C。
3. 删除作者、年份、政策、数据、案例和具体结论后，论证骨架是否仍然成立？如果成立，判 B。
4. 文本是否干净、段落完整、结构可复用、段落功能和可模仿内容已经标注？如果是，判 A。
5. 如果一个文件整体是 B 或 C，但其中少数段落达到 A，只把这些干净段落单独整理为 A 档短模板，不把整份文件升 A。

## 人工晋级规则

从 B/C 晋级到 A 的对象应是“干净段落”而不是整篇文件。A 档短模板至少应满足：

- 属于引言、文献综述、理论铺垫、现实背景、研究缺口或贡献段。
- 不含明显 OCR 污染、页眉页脚、断裂英文、空括号、缺失年份或错乱标题。
- 结构功能明确：背景铺垫、问题链、文献群落、机制推导、缺口收束、贡献定位之一。
- 删掉具体主题词后，句层结构仍可复用。
- 已标注“写法类型”“段落功能”“可模仿内容”“不可模仿内容”。

事实核验不是素材晋级的充分条件。素材即使是 A，也不能替代当前论文的事实核验；writer/check 写当前论文时仍必须回到用户材料、原文、PDF、MD 或可靠来源。
