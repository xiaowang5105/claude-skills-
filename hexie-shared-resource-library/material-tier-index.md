# hexie 素材提取质量分层索引

本索引用于指导 `hexie-writer` 和 `hexie-check` 读取素材。核心原则是“写法类型 × 提取质量”二维判断：

- 写法类型回答：这份材料属于哪一种开篇组织方式。
- 提取质量回答：这份摘录现在能被 AI 安全学到什么程度。

目录名和写法类型都不是质量等级。A/B/C 只表示当前这份文本的提取质量和可复用强度，不表示这种写法本身高级或低级，也不评价原论文的学术价值。

## 目录结构

素材库采用 A/B/C 三档为第一层、八种写法为第二层的结构：

```text
hexie-shared-resource-library/
├── tier-a-complete-structure-templates/
├── tier-b-skeleton-structure-templates/
└── tier-c-style-corpus/
```

同一种写法可以同时存在 A/B/C 三档素材。当前 A 档可以逐步从 C 档 MinerU/OCR 原始材料或 B 档骨架材料中人工截取干净段落补充；原始整篇材料仍留在 C 档作为回查入口。

## 二维判断规则

先判断写法类型，再判断提取质量：

1. 写法类型：主题线分组、概念论证块、缺口驱动、机制推导、对比型、政策脉络、时间演进、概念辨析。
2. 提取质量：A、B、C。
3. 使用方式：同一种写法可以同时存在 A/B/C 不同提取质量素材；writer/check 不得因为某个当前文件是 B 或 C，就否定这种写法本身。
4. 事实边界：无论 A/B/C，都不能作为当前论文的现实背景事实或文献事实依据。

## A/B/C 定义

| 层级 | 名称 | 判断标准 | 可用于 | 不可用于 |
|------|------|----------|--------|----------|
| A | 高质量摘录 | 已从论文中截出干净、完整、边界清楚的引言、文献综述、理论铺垫、现实背景、研究缺口或贡献段；OCR 基本干净；没有正文其他部分混入；开头有写法类型、素材等级、可学习/不可学习内容说明。 | 学习完整结构、问题链、文献群落组织、贡献定位、句层节奏和收束方式。 | 当前论文事实依据；照搬原文；替代引用核验；模仿具体年份、政策、数据、案例或原文结论。 |
| B | 可用摘录 | 已截取相关开篇段落，但仍有局部格式不干净、事实/引用密度过高、段落边界不够理想或标注不足；删除或忽略事实后，论证骨架仍可学习。 | 去事实/引用后学习判断链、句群推进、转折方式、收束方式和结构骨架。 | 引用事实、背景事实、整段原样模仿、具体机制方向、具体政策判断。 |
| C | 原始/低质量材料 | 整篇 MinerU/OCR 输出、历史大素材、OCR 污染明显、结构断裂、混入正文其他部分，或尚未人工截取。 | 关键词搜索后参考 1-3 段词语、短语、连接方式和中文经管论文气口。 | 结构模板、引用事实、背景事实、标点格式、引用格式、段落骨架。 |

简单说：

```text
A = 干净完整的开篇摘录，可以学完整结构
B = 有用但不够干净的摘录，去事实/引用后学结构骨架
C = 原始材料或低质量材料，只学词语和气口
```

## 默认读取顺序

1. 先判断任务类型：引言、文献综述、理论铺垫、现实背景、研究缺口、贡献段。
2. 再判断适合的写法类型：八种组织方式中哪一种或哪几种最匹配。
3. 在对应写法类型下查找提取质量：优先 A；没有 A 时使用 B；C 只用于语言风格。
4. 使用 A 时，学习结构、问题链、句群推进和收束方式，但不得把其中事实写成当前论文事实。
5. 使用 B 时，必须先删除或忽略作者、年份、政策、数据、案例、具体结论和引用事实，只学习剩余判断链、句群推进、转折方式和收束方式。
6. 使用 C 时，只能关键词搜索，每次最多取 1-3 段相近语料，用于去 AI 腔和中文经管论文气口。
7. 所有政策、年份、事件、数据、企业案例、制度背景、国际形势和文献发现，都必须回到用户材料、原文、PDF、MD 或可靠来源核验。

## 新增素材快速判断流程

新增素材时按以下顺序判断：

1. 整篇 MinerU/OCR 输出先放 C，作为原始备份和待筛选入口。
2. 从原始 MD 中截取引言、文献综述、理论铺垫、现实背景、研究缺口或贡献段。
3. 若截取段有严重 OCR 污染、断句错乱、空括号、残缺英文、页眉页脚混入，或不是完整开篇段落，判 C。
4. 若截取段有用但事实/引用密度高、局部格式不干净、段落边界不够理想，删除事实后论证骨架仍成立，判 B。
5. 若截取段干净、完整、边界清楚，并在文件开头写明“写法类型、素材等级、可学习、不可学习”，判 A。
6. 如果一个原始文件整体是 C，但其中少数段落达到 A，只把这些干净段落单独复制到 `tier-a-complete-structure-templates/`，不把整份文件升 A。

## A 档最小说明格式

A 档不要求复杂逐句标注，但文件开头至少保留以下说明：

```markdown
# [作者/年份/主题简名]

写法类型：[八种写法之一]
素材等级：A
可学习：[结构、问题链、转折方式、收束方式等]
不可学习：[具体年份、政策事实、作者结论、数据、引用事实等]

## 原文摘录

[截取后的干净开篇段落]
```

事实核验不是素材晋级的充分条件。素材即使是 A，也不能替代当前论文的事实核验；writer/check 写当前论文时仍必须回到用户材料、原文、PDF、MD 或可靠来源。
