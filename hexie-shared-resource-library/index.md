# hexie 素材库索引

## 设计原则

- **每一条素材都可以追溯到一篇已发表的论文。** 不使用AI生成的范例。
- **A分类放引言+文献综述。** 按论证类型组织，与B分类骨架一一对应。阶段三写完后取同类型A论文对照文本质量。
- **B分类放骨架。** 论证骨架来自真实论文的引言结构分析，用于阶段一搭论证链。

## 目录结构

```
hexie-shared-resource-library/
├── index.md                    ← 本文件
├── how-to-use.md               ← 操作规则（writer/check按需读取）
├── a-cards/                    ← A分类：引言+文献综述（按论证类型）
│   ├── 01-缺口驱动/
│   ├── 02-机制推导/
│   ├── 04-主题线分组/
│   └── 06-政策脉络/
└── b-corpus/                   ← B分类：论证骨架（按论证类型）
    ├── 01-缺口驱动/
    ├── 02-机制推导/
    ├── 04-主题线分组/
    └── 06-政策脉络/
```

## A分类：引言+文献综述

阶段三写完后，取同类型A论文逐段对照文本质量：段尾收束句字数、长短落差、关联词密度、破折号频率、段首是否判断先行。不比对论证结构。

| 类型 | 论文 |
|------|------|
| 01-缺口驱动 | 周黎安（2007）、余泳泽、潘妍（2019） |
| 02-机制推导 | 赵岳、谭之博（2011）、余淼杰（2010） |
| 04-主题线分组 | 马述忠、房超（2021） |
| 06-政策脉络 | 林毅夫、沈艳、孙昂（2020） |

## B分类：论证骨架

阶段一搭论证链时取匹配类型参考判断链推进。

| 类型 | 来源A论文 | 识别特征 |
|------|---------|---------|
| 01-缺口驱动 | 周黎安（2007）、余泳泽（2019） | 现象悖论→现有解释→逐层反驳→替代框架 |
| 02-机制推导 | 赵岳（2011）、余淼杰（2010） | 问题→现实创新→自然语言机制→理论模型 |
| 04-主题线分组 | 马述忠（2021） | 技术变革→政策脉络→文献双线→三点创新 |
| 06-政策脉络 | 林毅夫（2020） | 外生冲击→政策回应→识别挑战→方法策略→贡献 |

## 素材质量标准

1. **来源可追溯**：作者、年份、期刊、段落位置完整
2. **文本已验证**：与PDF原文对照，确认无OCR错误
3. **零AI生成**：所有范例来自已发表的真实论文
4. **可扩展**：后续新增论文按同样标准加入
