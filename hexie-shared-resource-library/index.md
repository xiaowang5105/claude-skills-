# hexie 素材两层索引

## 设计原则

- **A 档学句子。** 最难被规则描述的（词感、节奏、收束力）拆到句子级，每句带标注。
- **B 档学段落。** 论证骨架 + 原始论文全文同放一处，搭结构和看原文落笔都在这里完成。

## 目录结构

```text
hexie-shared-resource-library/
├── a-sentence-cards/      ← 句子级：技法卡片
├── b-structure-corpus/    ← 段落级：论证骨架 + 原始全文
├── index.md      ← 本文件
└── how-to-use.md           ← 操作规则
```

---

## A 档：句子卡片

**定位**：从优质中文经管论文开篇段落中，人工截取单个句子或句对，按写作技法分类，每句带简短标注。

**用途**：第三轮逐句修文本时，一句一句对着卡片查。节奏不对查落差，收不住查找束力，关联词硬查位置，词感不对查气口。不是读一篇，是写一句、发现一个问题、拿一张卡对照。

**不可用于**：事实依据、照搬原文、替代引用核验。

### 子分类

| # | 技法 | 学什么 |
|---|------|--------|
| 01 | 收束力 | 段尾短句怎么收住前面的长铺陈 |
| 02 | 长短落差 | 长句铺陈与短句切断的搭配节奏 |
| 03 | 关联词位置 | 关联词藏在句首/句中/逗号后；不用关联词靠两句对峙推进 |
| 04 | 判断先行 | 段首和句首先给学术判断，再给事实或引用 |
| 05 | 无标签推进 | 不靠声明句，靠句间逻辑自然推送文献关系 |
| 06 | 气口与词感 | 自然学术用词、动词选择、避免 AI 腔的对照替换 |

## B 档：段落结构语料

**定位**：按论证类型组织的段落级素材。每个子目录下同时放论证骨架和原始论文全文。

**用途**：第二轮（结构与论证）搭段落结构前，取 3 个匹配类型的骨架看判断链推进；需要看原文怎么落笔时直接翻同目录下的全文。

**不可用于**：事实依据、直接照搬内容。

### 子分类

| # | 论证类型 | 识别特征 |
|---|---------|---------|
| 01 | 缺口驱动 | 背景 → 已有研究不足 → 本文切入 |
| 02 | 机制推导 | 概念界定 → 渠道 A → 渠道 B → 收束 + 假设 |
| 03 | 概念论证块 | 概念拆解 → 理论关系 → 推导假设 |
| 04 | 主题线分组 | 两类/多类研究 → 群落关系 → 收束缺口 |
| 05 | 对比型 | 对立观点 → 分歧证据 → 本文立场 |
| 06 | 政策脉络 | 政策演变 → 制度背景 → 研究问题 |
| 07 | 概念辨析 | 概念边界 → 定义演变 → 本文界定 |

`raw-papers/` 存放尚未按类型归类的原始论文全文。

## 两层快速对比

| | A 档 | B 档 |
|---|------|------|
| 粒度 | 句子/句对 | 段落骨架 + 全文 |
| 学什么 | 词感、节奏、收束力 | 论证推进逻辑 |
| 怎么读 | 按技法取 5-10 张 | 按类型取 3 个骨架 |
| 用于哪轮 | 第三轮（语言与节奏） | 第二轮（结构与论证） |
| 不可用于 | 事实、照搬 | 事实、照搬 |
