## 骨架：对比型（正反两面 → 立场）
**来源**：吴剑峰（年份待确认），《[期刊待确认]》
**判断链**：
1. 国际研发合作的地域广度与技术创新绩效之间不是简单的线性关系
2. → 正面：地域分布越广 → 异质性知识越多 → 创新绩效↑
3.   → 接触各国先进知识 → 学习效率↑
4.   → 适应多样化顾客需求 → 新产品可能性↑
5. → 反面：地域分布过广 → 空间距离阻碍隐性知识转移
6.   → 管理层注意力分散 → 协调成本↑
7.   → 制度距离 → 研发风险↑
8. → 收束：地域广度与创新绩效呈倒 U 型关系（假设）
9. → 调节：企业资源禀赋影响曲线形状
**结构特征**：正面列出 → 反面列出 → 提出非线性假设 → 加入调节变量。
