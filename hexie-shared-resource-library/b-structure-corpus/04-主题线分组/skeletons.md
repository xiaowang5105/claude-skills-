## 骨架：主题线分组（两线并行 → 收束缺口）
**来源**：hexie-writer 改写产出（半导体产业政策）
**判断链**：
1. 半导体供应链韧性与产业政策设计已深度嵌合
2. → 线1（政策有效性）：实地调研 + 比较研究确认财政激励有效引导产能布局
3. → 但政策力量有条件：需匹配本地吸收能力 + 稳定可信的政策环境
4. → 收束1：有效性取决于政策与产业现实的精准嵌合
5. → 线2（战略升维）：半导体供应被纳入经济安全框架
6.   → 欧盟：供应链治理 = 经济安全 + 国家安全
7.   → 日本：多边协调将战略转化为韧性增强
8. → 收束2：财税工具承载技术主权与供应安全使命
9. → 两线交汇：同为财税工具，税收优惠与政府补贴的作用逻辑不同 → 假设H1
**结构特征**：两线各自独立推进，在交汇处引出本文的区分（税收优惠 vs 政府补贴）。
