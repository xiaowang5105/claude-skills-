# B分类：主题线分组 + 政策脉络混合型 — 论证骨架

**来源论文**：马述忠、房超（2021），《跨境电商与中国出口新增长——基于信息成本和规模经济的双重视角》，《经济研究》

**论证类型**：政策脉络 + 主题线分组

**结构特征**：技术变革背景→政策文件密集出台→政策表格（引言内嵌）→研究问题→文献按主题线分组→三点创新逐条宣告。最大的形式特征是引言中嵌入了政策文件表格——这是政策脉络型论文中一种有效但少见的写法。

---

## 判断链

```
第1步 [技术背景] 第三次工业革命（互联网）深刻影响社会经济各领域。
    → 跨境电商是"外贸新旧动能转换的重要推动力量"和"外贸增长的新引擎"

第2步 [政策脉络] 自2012年以来，国务院、商务部等出台几十余份跨境电商政策文件。
    → 同时设立跨境电商试点城市和综合试验区
    → **嵌入政策表格**（13条政策，2012-2020，含颁布单位和文件名称）

第3步 [研究问题] "跨境电商产业政策的贸易促进效应到底有多大？通过什么方式推动外贸增长？"
    → 三个递进问题：效应大小→实现机制→未来政策方向

第4步 [文献分组] 两组文献：
    (a) 出口增长文献（传统因素→互联网→电子商务→跨境电商）
    (b) 网络平台文献（长尾效应、价格粘性、机制设计、机器翻译）
    → 两组文献各有自己的推进逻辑，最后收束到"本文的贡献"

第5步 [三点创新] 逐条宣告，每条含"已有研究X→本文做Y"的结构

第6步 [假设提出] 两个理论假说分别在机制分析中提出（假说一：信息成本→扩展边际；假说二：规模经济→集约边际）
```

---

## 独特技法：引言中嵌入政策表格

马述忠2021在引言第2段后直接插入了一个13行的政策文件表格（表1 代表性跨境电商产业政策），列出2012-2020年间国务院和各部委颁布的关键政策文件。

**这个做法为什么有效：**
- 政策脉络型论文需要展示"政策密集出台"的事实——表格比文字更有说服力
- 表格节省了大量文字篇幅——如果每份文件用一句话描述，13条政策需要约300字
- 表格本身构成了论证——读者扫一眼表格就能感受到"政策确实很密集"
- 表格放在引言中（而非后文"制度背景"节），让政策背景成为论证的一部分而非附录

**使用条件：**
- 政策数量足够多（≥8条）且时间跨度清晰
- 表格简洁（3列以内：时间、颁布单位、文件名称），不做复杂排版
- 表格之后立即回到论证主线，不沉溺于政策细节

---

## 独特技法：两组文献各成推进线，最后收束

马述忠2021的文献部分组织了两条独立的线：

**线1——出口增长文献**（从远到近推进）：
传统出口增长因素 → 互联网与出口 → 电子商务与出口 → 跨境电商与出口（最前沿、文献最少）

**线2——网络平台文献**（从宏观到微观推进）：
平台宏观效应（长尾）→ 平台价格机制 → 平台信息披露与评分 → 平台机器翻译与贸易

两条线各自独立推进，最后在"已有文献对跨境电商的贸易促进作用关注不多，对规模经济有所忽视"这一点上收束——这正好是本文的贡献所在。

---

## 三点创新的结构化格式

马述忠2021的三点创新集中在同一段内宣告，每点一句话，结构高度一致——"已有研究……而本文……"：

> "第一，已有研究跨境电商与出口之间关系的文献主要以定性分析为主，或者从侧面探讨跨境电商对贸易成本的降低作用，而本文创新性地利用跨境电商产业政策展开定量分析，将跨境电商与出口增长的研究有机结合起来。"
> 
> "第二，本文的研究不仅仅局限于总量上的分析，而是将传统的贸易流量结构性分解方法应用于跨境电商的研究中，从二元边际的角度探讨跨境电商促进出口增长的实现机制。"
> 
> "第三，已有研究跨境电商与贸易的文献集中于跨境电商如何降低贸易成本，本文基于信息成本和规模经济的双重视角，探讨跨境电商促进出口增长的理论机制，特别是分析了需求方规模经济在平台贸易中的重要作用，提供了一个新的研究视角。"

**为什么有效**：每一点都遵循同一模板——先说已有研究做了什么（或没做什么），再说本文做了什么不同的事。三点之间不是并列罗列，而是从方法到视角的递进：第一点讲方法创新（定性→定量），第二点讲分析深度（总量→结构分解），第三点讲理论视角（单维度→双维度）。读者读完三点，知道这篇文章在三个层面上推进了文献。

**可复用模板**：
"第一，已有研究……而本文……"
"第二，本文不仅仅……而是……"
"第三，已有研究集中于……本文基于……双重视角……"

**适用场景**：当文章的创新点共享同一支文献背景（不需要每点独立展开一段微型文献综述），且三点之间存在方法→深度→视角的递进关系时，用集中宣告比逐段展开更高效。
