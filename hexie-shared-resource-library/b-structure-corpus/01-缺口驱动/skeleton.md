# B分类：缺口驱动型 — 论证骨架

## 来源1：周黎安（2007），《经济研究》

**结构特征**：现象悖论→现有解释→逐层反驳→替代框架。核心张力——"增长奇迹与制度排名倒挂"——逐层推进，每一层反驳现有解释的一个侧面，同时为替代框架积累势能。

### 判断链（12步）

```
第1步 [现象判断] 中国经济近30年高速增长是"增长奇迹"。
    ↓ 但
第2步 [悖论] 增长理论预言的条件中国都不具备 → "中国不应该有经济奇迹发生。"
第3步 [理论引入] 制度决定增长（North, Acemoglu等）
    ↓ 然而（升级）
第4步 [悖论加深] 中国制度排名极低但增长极快 → "这又如何解释呢？"
第5步 [方向锚定] 关键是激励，中国的激励制度形式不同于西方
第6步 [问题扩展] 增长奇迹的另一面是问题积累
第7步 [聚焦官员] 地方政府角色罕见，Easterly说政府是头号杀手→中国如何解决激励？
第8步 [介绍现有理论] 中国特色联邦主义：行政+财政分权
第9步 [反驳1：稳定性] 分权在变但激励不变→有更基本的激励
第10步 [反驳2：市场维护] 市场问题仍严重→需要新理论视角
第11步 [更深追问] 同一体制，改革前后为何不同？
第12步 [本文回答] 晋升锦标赛模式：集权+激励兼容，双刃剑
```

## 来源2：余泳泽、潘妍（2019），《经济研究》

**结构特征**：悖论先行（"一般规律"vs中国事实）→ 文献按市场性/政府性分类 → 缺口（政府性因素视角少有人做）→ 三点创新逐条编号。与周黎安2007的"反驳现有理论"不同，余泳泽2019是"两支文献各看了问题的一面，但缺少从某个特定因素切入的解释"。

### 判断链

```
第1步 [悖论先行] "一般规律"是服务业随经济增长而升级。但中国事实相反：
    2004-2014年生产性服务业占比仅增2.1个百分点，远低于发达国家"四个70%"标准。
    → 收束："服务业发展水平与经济增长速度脱节现象由何而来？"

第2步 [文献分类] 影响经济增长的因素：市场性（要素、需求） + 政府性（晋升锦标赛）。
    影响服务业发展的因素：基础性（人力资本、技术、需求） + 一般性（政府职能、开放、环境）。
    ↓ 但
第3步 [缺口] 从政府性因素解读"高速增长+服务业滞后并存"的文献尚不多见。
    谭洪波和郑江淮(2012)做了市场性因素的解释，但政府性因素视角缺位。
    核心问题：经济增长目标约束是否导致了服务业结构升级滞后？

第4步 [创新宣告] 三点创新：
    (1) 视角：从经济增长目标约束解释"增长-服务业之谜"
    (2) 数据：手工搜集230个地级市政府工作报告中的增长目标
    (3) 意义：为服务业"结构刚性"提供新思路
```

### 独特技法：悖论用数据立住

余泳泽2019第一段的关键动作：先说出"一般规律"是什么，然后说中国不符合。用了具体数字：
- 2004-2014年生产性服务业占比从35.0%→37.1%，仅增2.1个百分点
- 与发达国家"四个70%"标准相去甚远

两个数字就让读者感受到"这确实是个谜"——不需要说"鲜有研究关注"。

### 独特技法：文献按分析视角分类

不按"谁研究了什么"列举文献，而是按**分析视角**分类：
- 经济增长因素 → 市场性 vs 政府性
- 服务业发展因素 → 基础性 vs 一般性

分类本身就在论证——它展示了"政府性因素"是一个独立的、值得关注的解释维度。
