# 06 政策脉络

---

## 骨架：政策脉络（政策演变 → 研究问题）
**来源**：聂辉华、阮睿、沈吉（2020），《经济研究》
**判断链**：
1. 现有研究用宏观 EPU 指数衡量经济政策不确定性
2. → 两类做法：外生事件（选举/峰会）+ 新闻文本 EPU 指数
3. → EPU 的局限1：国家层面指标，同一时间对所有企业只有一个观测值 → 无法加入时间固定效应
4. → EPU 的局限2：假设所有企业同质感知不确定性 → 现实中地区、行业、个体预期各不相同
5. → 理论需求：不同企业的不确定性感知有差异 → 需要企业层面指标
6. → 方法基础：年报文本挖掘已有成熟应用（可读性、语调、竞争策略）
7. → 政策基础：证监会要求年报披露经营不确定性
8. → 本文切入：用上市公司年报文本构建企业层面经济政策不确定性感知指标（FEPU）
9. → 检验 FEPU 对实业投资和金融资产配置的影响
**结构特征**：既有指标 → 两个局限性 → 理论需求 + 方法可行性 → 本文指标 + 检验。
