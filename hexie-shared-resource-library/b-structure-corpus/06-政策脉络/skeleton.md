# B分类：政策脉络型 — 论证骨架

**来源论文**：林毅夫、沈艳、孙昂（2020），《中国政府消费券政策的经济效应》，《经济研究》（发表年份待确认，可能为2021）

**论证类型**：政策脉络型

**结构特征**：外生冲击→政策回应→识别挑战→方法策略→核心发现→三点贡献逐段展开。与缺口驱动型不同，政策脉络型不围绕"现有理论解释不了现象"来组织，而是围绕"这个政策到底有没有效果、怎么科学评估"来推进。核心张力不在理论和现象之间，而在"政策意图"和"因果识别的困难"之间。

---

## 判断链（政策脉络型特有结构）

```
第1步 [冲击描述] 新冠疫情导致生产、消费、外贸同时萎缩，中国2020Q1经济同比下降6.8%。
    ↓
第2步 [政策回应] 消费券是中国历史上第一次大规模通过发放消费券来应对经济冲击。
    → 核心问题："是否应当加大发放规模取决于消费券能否达到刺激消费的初衷。"
    
第3步 [识别挑战] 直接比较发券前后的消费变化会产生三类估计偏误：
    (a) 消费反弹不都由消费券带来
    (b) 核销支出不都是被消费券撬动
    (c) 消费券发放并非随机
    → 这一段不是"文献综述"，而是"方法论挑战的前置声明"
    
第4步 [方法策略] DID+DDD识别效果 + 安慰剂检验 + 广义合成控制法 + 合成控制法
    → 方法选择直接回应第3步的三类偏误
    
第5步 [核心发现] 三点发现，每点对应一个政策含义

第6步 [贡献1] 消费券刺激消费 → 丰富疫情对经济影响的文献
    → 贡献段有自己的论证：现有文献做了什么→缺什么→本文补什么

第7步 [贡献2] 补充消费券研究 → 发达国家的证据不一致，中国证据缺失
    → 贡献段包含自己的微型文献综述

第8步 [贡献3] 为"有为政府"理论提供实证支撑
    → 贡献不仅对文献，还对理论框架
```

## 独特技法：三点贡献逐段展开

林毅夫2020的贡献段有三段，每段独立成段、各自包含微型论证：

**贡献段的结构模板**：
```
"第X，[贡献方向]。  [2-3句现有文献的局限/缺失]。 [1-2句本文如何填补]。 [1-2句本文发现的意义]。"
```

这个结构比周黎安2007的贡献段更结构化。周黎安的贡献嵌入在论证推进中（P10-P11），林毅夫则是显式列出、逐段展开。

### 贡献段1（节选）：
> "第一，从消费券刺激消费的角度，丰富了新冠肺炎疫情对经济影响的文献。现有国际文献已经从……等多个角度展开了丰富的研究。……但综合国内外文献可知，尚缺少评估疫情下消费券影响的实证分析。本文的发现有助于理解在疫情背景下，在世界最大的发展中国家发放消费券对经济复苏的效果。"

**技法**：先承认现有文献的广度（"多个角度""丰富的研究"），再精确指出缺失（"尚缺少评估疫情下消费券影响的实证分析"），最后宣告本文贡献。

### 贡献段2（节选）：
> "第二，本文丰富和补充了消费券相关的研究。对于消费券是否能刺激消费这一问题，经济学理论和实证分析均无定论。……实证研究结果也莫衷一是。……简言之，现有文献主要评估了发达国家和我国台湾地区的消费券发放效果，少有对发展中国家发放消费券效果的评估，更缺少对中国的研究。"

**技法**：先展示理论争论（凯恩斯 vs 弗里德曼），再展示实证分歧（正反证据都有），最后精确划出空白——"少有对发展中国家……更缺少对中国"。这比"鲜有研究"有力得多，因为前面的理论争论和实证分歧证明了"这是一个真实存在的open question"，中国的空白因此有了全球学术意义。

## 值得注意：AI腔出现在真实论文中

本文使用了"还值得注意的是"——恰好在hexie-check的AI腔清单上。但这是2020-2021年发表的《经济研究》论文，作者是林毅夫等资深学者。这说明：
1. "还值得注意的是"在2020年之前就是中文学术写作的常用过渡语
2. AI模型大量使用了这些表达后，它们才变成了AI腔
3. check的AI腔检测需要考虑时代语境——不能一刀切
