## 骨架：概念论证块（递进型）
**来源**：李雪松（年份待确认），《[期刊待确认]》
**结构**：围绕"开放式创新"概念逐层递进，每层引入新理论视角。
**判断链**：
1. 开放式创新：外部知识、外部市场路径与内部知识同等重要
2. → 企业难以独立完成创新，需与多样化主体合作 → 创新是协同过程
3. → 信息技术发展加剧环境不确定性，封闭式创新难以为继
4. → 融入全球创新网络是开放式创新的重要途径
5. → 与国内创新网络相比，全球网络的弱关系属性更有助于获取异质性知识
6. → 三个理论视角解释机制：资源基础观、社会网络理论、组织学习理论
7. → 但融入全球创新网络也存在成本：外来者劣势、制度距离、协调成本
8. → 收束：研发国际化不是免费过程
**结构特征**：概念定义 → 外延展开 → 理论支撑 → 边界条件 → 收束。
