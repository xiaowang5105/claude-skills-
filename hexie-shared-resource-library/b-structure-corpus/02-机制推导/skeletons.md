## 骨架：机制推导（并列双渠道）
**来源**：刘斌、李秋静（财经研究，2023）
**判断链**：
1. 美国对华出口管制通过两个渠道影响中国企业创新
2. → 渠道一（抑制创新产出）：出口管制阻碍中美间创新知识流动
3.   → 显性知识：产品和技术限制 → 无法模仿学习 → 创新产出↓
4.   → 隐性知识：人员流动和科技合作限制 → 知识输入受阻 → 创新产出↓
5. → 渠道二（促进创新投入）：出口管制提升企业自主创新动力
6.   → 机会成本降低：技术引进难度↑ → 自主创新相对成本↓
7.   → 预期收益提升：进口受限 → 市场份额扩大 → 创新租金↑
8. → 收束：两种渠道并存，方向相反，分别作用在创新产出和创新投入上
**结构特征**：两渠道并列展开，各自独立推导，最后以"并存而非矛盾"收束。
