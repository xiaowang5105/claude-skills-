# B分类：机制推导型 — 论证骨架

**来源论文**：赵岳、谭之博（2011），《电子商务、银行信贷与中小企业融资——一个基于信息经济学的理论模型》，《经济研究》

**论证类型**：机制推导型

**结构特征**：真实世界的制度创新→提出理论问题→不急于建模，先用自然语言讲清楚"这个机制怎么运作"→再引入模型→最后比较静态分析。引言极短但高效——一段讲问题+原因，一段讲现实中的新做法，一段抛出研究问题。与传统实证论文不同，理论模型论文的引言不需要大量文献综述来建立缺口——新现象本身就是缺口。

---

## 判断链

```
第1步 [问题陈述] 中小企业贷款难是经济发展的重要瓶颈。
    → 两个原因：(1)信息不对称→信贷配给 (2)抵押品不足
    
第2步 [现实创新] 银行与电子商务平台合作推出新型贷款模式。
    → 具体案例：工商银行+阿里巴巴"易融通"(2007)、建设银行+"e保通"
    → 关键特征：无需抵押担保，但需要平台交易记录

第3步 [问题抛出] 四个递进问题：
    "能否有效缓解融资难题？成功需要什么条件？解决哪类企业？机制何在？政府如何发挥作用？"
    → 四个问题从"是否有效"到"为什么有效"到"如何放大效果"，层层深入

第4步 [机制展开] 不建模，先用自然语言分析四个机制：
    (1) 增大违约成本（"互联网全网通缉""网络公示""终止服务"）
    (2) 建立网络信用体系（会员制+交易记录→信用档案）
    (3) 风险共担（"风险池"）
    (4) 规模经济（固定成本分摊）
    
第5步 [模型验证] 构建信息不对称理论模型，证明四个机制如何消除信贷配给
    
第6步 [比较静态] 分析各因素的影响方向和边界条件
```

---

## 独特技法：用自然语言讲机制，然后才建模

赵岳2011最值得学的是第二节——在引入数学模型之前，先用4个"第一/第二/第三/第四"把机制讲清楚：

> "第一，电子商务的引入增大了贷款企业的违约成本。……一旦授贷企业出现坏账，可以对用户进行'互联网全网通缉'，以'网络公示'和'终止服务'等手段有效提升了企业的违约成本。"

这是理论论文引言的核心技法：**在建模之前，让读者相信这个机制在现实中是存在的、重要的。** 模型只是把已经讲清楚的机制形式化。

## 问题驱动的引言结构

赵岳2011的引言只有3段，但提出了4个递进问题：

| 问题 | 层次 |
|------|------|
| "能否有效缓解中小企业的融资难题?" | 是否有效（存在性） |
| "它的成功需要什么条件，又主要解决了哪类企业的融资难题?" | 适用边界 |
| "电子商务平台降低银企间信息不对称，进而消除中小企业信贷配给的机制何在?" | 为什么有效（机制） |
| "政府又如何在其中发挥积极的作用?" | 政策含义 |

四个问题从表层到深层递进，且——关键——**每个问题都在后面的正文中有对应章节回答。** 这不是"本文研究了……"的宣告，而是"请读者带着这些问题读下去"的邀请。
