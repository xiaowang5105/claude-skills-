## 骨架：概念辨析（概念界定 → 维度拆解 → 假设推导）
**来源**：hexie-writer 改写产出（动态能力调节）
**判断链**：
1. 隐含前提：企业对政策的吸收和转化能力同质 → 事实并非如此
2. → 三篇异质性文献 → 同一政策效果不均等
3. → 但已有研究只描述"什么条件下更强"，缺乏统一理论框架
4. → 动态能力理论提供框架：感知、把握、重构三大功能
5. → 本文将动态能力分解为三个维度（在产业政策情境中的具体化）：
6.   → 政策感知能力：从政策信号中提取有效信息 → 增强识别
7.   → 政策捕获能力：获取和利用政策资源 → 落地转化
8.   → 政策重构能力：重组资源基础以适应环境变化 → 结构性改善
9. → 收束：动态能力放大产业政策对韧性的促进作用 → 假设 H3
**结构特征**：先论证"需要框架" → 引入理论 → 拆解为可操作化维度 → 推导调节效应假设。
