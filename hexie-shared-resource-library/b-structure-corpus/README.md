# B分类：段落结构语料

按论证类型分类。每个子目录下放论证骨架（skeleton.md），对应论文全文在 `../a-cards/` 下。

## 使用方式

阶段一定内容时，取匹配类型的骨架看判断链推进。需要看原文怎么落笔时翻 `../a-cards/` 对应目录下的全文。不照搬内容，只复用推进逻辑。
