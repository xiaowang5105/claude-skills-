# hexie shared resource library

`hexie-writer` 和 `hexie-check` 共用的资源库。

## 结构

```text
hexie-shared-resource-library/
├── index.md                    ← 分层索引（先读）
├── how-to-use.md               ← 操作规则
├── a-sentence-cards/           ← 句子级：技法卡片
│   ├── 01-收束力/
│   ├── 02-长短落差/
│   ├── 03-关联词位置/
│   ├── 04-判断先行/
│   ├── 05-无标签推进/
│   └── 06-气口与词感/
└── b-structure-corpus/         ← 段落级：骨架 + 原始全文
    ├── 01-缺口驱动/
    ├── 02-机制推导/
    ├── 03-概念论证块/
    ├── 04-主题线分组/
    ├── 05-对比型/
    ├── 06-政策脉络/
    ├── 07-概念辨析/
    └── raw-papers/              ← 未归类的原始论文
```

## 两层分工

| | A 档 | B 档 |
|---|------|------|
| 粒度 | 句子/句对 | 段落骨架 + 全文 |
| 学什么 | 词感、节奏、收束力 | 论证推进逻辑 |
| 用于哪轮 | 第三轮（语言与节奏） | 第二轮（结构与论证） |
| 不可用于 | 事实依据、照搬 | 事实依据、照搬 |

## 事实边界

无论 A/B，素材都不能作为现实背景事实或文献事实的最终依据。引用准确性必须回用户材料、原文、PDF 或可靠检索结果核验。OCR 错误（空括号、缺年份、残缺英文、错断句）不能模仿。
