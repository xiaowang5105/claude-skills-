# hexie shared resource library 资源索引

本目录是 `hexie-writer` 和 `hexie-check` 共用的资源库。推荐目录名为 `hexie-shared-resource-library/`。核心原则是区分三件事：模板、语料、事实依据。

## 先读质量索引

若存在 `material-tier-index.md`，writer/check 必须先读取它，再决定使用哪些素材。该索引采用“写法类型 × 素材质量”的二维判断：

- 写法类型：主题线分组、概念论证块、缺口驱动、机制推导、对比型、政策脉络、时间演进、概念辨析。
- 素材质量：A/B/C 只决定 AI 可以安全学到什么程度，不评价这种写法本身好坏。
- 使用强度：A 可学完整结构；B 去事实/引用后学结构骨架；C 只学词语和气口。

目录名称和写法类型只表示入口和用途，不自动等于素材等级。具体等级以 `material-tier-index.md` 为准。

## 资源层级

| 目录或文件 | 用途 | 使用限制 |
|------------|------|----------|
| `structure-template-library/` | 结构模板入口，存放问题链、现实背景铺垫、文献群落、贡献定位、句层节奏、证据分布等写法材料 | 目录本身不等于 A 档；必须按 `material-tier-index.md` 判断具体文件或段落等级；不把其中发现或背景事实直接当成当前论文事实 |
| `limited-reference-templates/` | 局部参考模板入口，存放概念铺垫、机制推导、政策脉络、概念辨析等场景材料 | 目录本身不等于 B 档；若当前素材为 B，只能删除引用和事实后学习判断链，不整篇模仿，不作为事实依据 |
| `low-trust-style-corpus/` | 低可信风格语料入口，用于中文经管论文用词、连接方式、气口、反 AI 腔 | 通常只按 C 档使用：只参考词感和句式，不作文献事实、现实背景事实或结构模板依据 |
| `low-trust-style-corpus/raw-ocr/` | 低可信原始语料，存放 MinerU/OCR 转换材料和历史大素材 | 可能有 OCR 污染，不模仿空括号、缺年份、残缺英文、错断句，不作为事实来源 |

## 操作规则

`workflow-rules.md` 存放 writer/check 共用的工作细则，包括适用范围、事实来源优先级、八种组织方式、writer-check 循环、阻塞条件、前置检查格式、13 条检查清单、现实背景核验、文献引用准确性和检查报告格式。writer/check 只在需要对应细则时读取相应章节。

## 模板与原料关系

`structure-template-library/` 和 `limited-reference-templates/` 是模板入口，不是天然 A/B 等级。主题线分组、政策脉络、时间演进等是写法类型，不是质量等级。一个写法文件可以整体是 B，但其中少数段落达到 A；这种情况下，只把干净段落单独整理为 A 档短模板，不把整份文件升 A。

`low-trust-style-corpus/raw-ocr/legacy-examples.md` 是历史大素材，属于 C 档词感语料和待筛选原料。它和模板入口不是同步副本；维护时可以从中人工筛选干净段落，重新标注后进入模板入口。

## 使用规则

- 写结构：先读 `material-tier-index.md`，先判写法类型，再判素材等级。有 A 档匹配材料时，学习完整结构；没有 A 档时，读 B 档材料，但必须删除或忽略作者、年份、政策、数据、案例和具体事实，只学习剩余判断链、句群推进、转折方式和收束方式。
- 去 AI 腔：搜索 `low-trust-style-corpus/` 或 `low-trust-style-corpus/raw-ocr/`，只取 1-3 段相近语料，提取用词、关联词、气口和句式节奏。
- 查文献事实：不要用本目录作最终依据。引用准确性必须回到用户提供的原文、PDF、MD、参考文献材料，或可靠检索结果。
- 查现实背景事实：不要用本目录作最终依据。政策、年份、事件、数据、行业事实、企业案例、制度背景或国际形势必须回到用户材料、官方来源、权威数据库、顶刊论文、NBER/CEPR working paper 或权威研究报告。
- 遇到 OCR 污染：保留词感，不保留污染形态。空括号、缺年份、错标点、残缺英文和断裂句都不能被模仿。

## 逐步整理方向

现阶段不清洗 MinerU 输出。历史大素材已迁入 `low-trust-style-corpus/raw-ocr/`，后续可以逐步从中挑出干净的引言、文献综述、理论铺垫和贡献段，整理进模板入口并重新标注 A/B；其余大段原文继续作为 C 档词感语料。
