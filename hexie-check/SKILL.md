# 文献综述质量检查

本 skill 对文献综述进行四维度质量检查，输出检查报告。不自动修改文本。

范例文件路径：`~/.claude/skills/hexie/examples.md`

---

## 执行流程

**Step 1. 进入Plan Mode，读全文，定位文献综述段落。**

**Step 2. 识别该文献综述的组织方式**（八选一）：

| # | 方式 | 识别特征 |
|---|------|---------|
| 1 | 主题线分组 | "与本文相关的第一类文献…第二类文献…" |
| 2 | 概念论证块 | 每小节一个概念部件，拼起来推假说 |
| 3 | 缺口驱动型 | 累积成果→局限→转移焦点→结构缺口→整合 |
| 4 | 机制推导型 | 以"X通过什么渠道影响Y"为纲 |
| 5 | 对比型 | 按对立观点组织，指明分歧点和证据 |
| 6 | 政策脉络型 | 沿政策演变组织 |
| 7 | 时间演进型 | 按发展阶段组织 |
| 8 | 概念辨析型 | 围绕概念定义演变组织 |

**Step 3. 打开 `examples.md`，找到对应组织方式的所有范例**，逐段通读。

**Step 4. 对目标文本逐维度检查打分（见下方四个维度检查细则）。**

**Step 5. 同时逐句过写作规则清单（见下方），逐条标记违规。**

**Step 6. 核对原文含义。** 逐条引用对比原文，检查改文是否扭曲了任何一篇原文献的发现含义。如果任何引用被改写了核心发现或结论方向 → 直接不合格，无须进入Step 7。

**Step 7. 联网验证 + 逻辑检验。**

1. **联网验证内容**：逐条检索关键文献的核心发现，确认改文表述与原文一致。
2. **逻辑链检验**：将段落内每句压缩为短语（A→B→C→D），看链是否完整。如果缺环节，标记为逻辑跳跃。

两项任一不通过 → 直接不合格。

**Step 8. 生成检查报告，格式见末尾。**

---

## 维度一：引用位置

目标：引用应嵌在括号里或从句中，不作为句子主语。

检查方法：
1. 逐段数出以"XX（年份）指出/发现/研究了/认为"开头的句子数。
2. 奠基性学者（Freeman首次定义概念、Powell给出首个证据、Chesbrough提出概念等）放在句首可豁免，但每段最多一处。
3. 统计：每段句首引用数 / 该段总引用数。

评分：
- 每段句首引用数 ≤ 1，且非奠基性引用不出现在句首 → **达标**
- 任意一段句首引用数 ≥ 2，或有非奠基性引用出现在句首 → **不达标**，列出具体句子

---

## 维度二：段首写法

目标：每段第一句是判断句，不是作者名。

检查方法：
1. 取每段第一句，去掉括号内的引用。
2. 判断该句是否构成一个完整的学术判断（可以是"关于X，研究发现…""X问题是…""与X相关的文献…"等）。
3. 如果去掉引用后句子不成立或不构成判断 → 违规。

评分：
- 全部段落首句均构成判断 → **达标**
- 有段落首句去掉引用后不成立或以作者名开头 → **不达标**，列出违规段序号和原句

---

## 维度三：连接词密度

目标：相邻句子之间用逻辑关联词承接，不是单纯物理分段。

检查方法：
1. 逐句检查相邻句子之间是否存在逻辑关联词。
2. 关联词包括但不限于：进一步地、与此一致、然而、与之相反、换言之、究其原因、这主要归因于、无独有偶、正是在这一背景下、由此引出、具体而言、一方面/另一方面、首先/其次/最后。
3. 计算每200字的关联词数量。

评分：
- 全文所有段落每200字均 ≥ 3 个关联词 → **达标**
- 任意一段每200字 < 3 个关联词 → **不达标**，列出该段文本和缺失位置

---

## 维度四：收束句

目标：每段结尾有明确收束判断，不悬空或直接跳下一段。

检查方法：
1. 取每段最后一句，判断其功能。
2. 合格的收束句类型：总结本段论点、指出该支文献的不足或空白、用问题过渡到下一段、提出本段发现对全文论证的含义。
3. 不合格：段落以引用的发现结尾而无任何判断、段落以描述结尾无推进、"断崖式"结尾直接跳到下一段。

评分：
- 全部段落尾句均构成收束 → **达标**
- 有段落尾句不具备收束功能 → **不达标**，列出违规段序号和尾句

---

## 写作规则辅助检查（逐条勾选）

此清单与四维度有交叉，但更细致。逐条勾选，标记违规位置。

- [ ] **规则1：引用位置** — 见维度一
- [ ] **规则2：段首** — 见维度二
- [ ] **规则3：转折后判断先行** — "然而""与之相反"之后，判断在前还是证据在前？证据在前则违规。
- [ ] **规则4：连接词密度** — 见维度三
- [ ] **规则5：收束句** — 见维度四
- [ ] **规则6：陈述句** — 是否有主动用破折号（——）和冒号（：）构建句子结构的情况？破折号每段超过1次？
- [ ] **规则7：叙述主体** — 是否出现"我们""我""笔者"？
- [ ] **规则8：AI腔** — 是否出现"随着...的发展""具有重要的理论意义和实践意义""在一定程度上""较为""鲜有研究探讨""有待进一步研究""值得注意的是"？
- [ ] **规则9：引用简洁** — 是否有"XX（2020）利用XX数据研究了XX，发现……"这类过度解释的引用？
- [ ] **规则10：语病** — 逐句朗读，是否有主谓搭配不当、宾语残缺、修饰语错位、句式杂糅、"的""地""得"混用、指代不明？
- [ ] **规则11：终极检验** — 删掉所有引用和括号，剩文是否为逻辑连贯的学术小品？

2. `原文件名_终稿.docx` — Word格式，通过pandoc转换
