# 中文经管论文开篇语言质量检查

## 角色

`hexie-check` 只检查文本的语言和节奏，不改文。它检查的是：这段引言读起来像不像中文经管论文。

事实核验和论证结构检查不在本 skill 的职责范围内——它们分别在 `hexie-writer` 的阶段二（文献核验）和阶段一（论证链确认）中完成。本 skill 只负责：**文本已经写出来了，检查语言写得好不好。**

## 检查项

### 节奏与收束

1. **长短差。** 每段最长句与最短句的字数差。如果差 < 25 字，且全段无明显短句断开 → 不通过。
2. **收束力。** 每段最后一句 > 30 字时，检查是否可将核心判断单独拎出以短句收束。连续两段收束句 > 30 字 → 不通过。
3. **句间节奏。** 连续 5 句以上字数接近，或长句连续堆叠无短句断开 → 不通过。

### 关联词与标点

4. **转折后判断先行。** "然而""但""与之相反"等转折后是否先给判断再给证据。证据先行 → 不通过。
5. **连接词方式。** 连续三句以上每句都以关联词开头 → 不通过。
6. **破折号密度。** 每段 > 1 次破折号 → 不通过。
7. **标点承担论证结构。** 破折号或冒号被用来代替句间逻辑推进 → 标记。

### AI 腔与语言自然度

8. **AI 腔。** "随着……的发展""值得注意的是""在一定程度上""较为""具有重要的理论意义和实践意义""以下将从 X 个方面展开""不仅……而且……更重要的是""基于上述分析""综上所述""呈现出……的特征/态势""发挥着……的作用"等表达 → 不通过。
8.5 **抽象概括无具体列举。** 出现"等多个角度""等多方面""等多种因素""等层面"等概括词时，检查前面是否有 ≥3 个具体列举项。只有 1-2 个或全部为抽象名词 → 不通过。
9. **事实堆叠。** 连续列出政策、年份、数据、事件而无问题意识 → 不通过。
10. **词汇适配。** 明显口语化、AI 腔词汇、无学科依据的用词 → 不通过。

### 语法与叙述

11. **叙述主体。** 出现"我们""我""笔者"时区分场景。方法策略段落（"我们采用""我们进一步""我们检验"等）允许；其他位置如无用户要求 → 不通过。
12. **语病。** 主谓搭配不当、宾语残缺、修饰语错位、句式杂糅、"的地得"混用、指代不明 → 不通过。

### 终极检验

13. **删引用后逻辑连贯。** 删掉所有引用和括号，剩余文本是否仍是逻辑连贯的学术小品。如果只剩事实堆叠或逻辑断裂 → 不通过。

## 报告格式

```markdown
# hexie-check 语言检查

**文件**：[文件名]
**检查结论**：通过 / 不通过

## 不通过项

| # | 检查项 | 位置 | 问题 | 修正建议 |
|---|-------|------|------|---------|
```

## 与 hexie-writer 的协作

`hexie-writer` 在阶段三（写文本 + 修语言）中调用本 skill。writer 写完正文后 → check 检查语言 → writer 定点修正 → check 复检。循环控制权在 writer。

语言修改不得新增事实、移动引用归属或重写文献含义。若改动影响结构或引用，退回 writer 阶段三重新调整正文。

## 适用边界

适用：引言、导论、文献综述、理论铺垫、现实背景、研究背景、研究问题、研究缺口、边际贡献、贡献段。

不适用：数据处理、模型设定、实证结果、稳健性、机制检验、异质性、结论、政策建议。
