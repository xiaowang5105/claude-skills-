# PDF-MD 对比检查

## 目标

确认 md 与 PDF 原文**无差别**——不丢字、不加字、不改字。若 md 不存在，自动用 MinerU 3.x 将 PDF 转为 md 后再进入对照流程。

## 前置依赖

- **MinerU 3.x**（命令 `mineru`），安装参见 [MinerU 官方仓库](https://github.com/opendatalab/MinerU)
- 模型通过 ModelScope 下载：`SET MINERU_MODEL_SOURCE=modelscope && mineru-models-download`

## 双引擎架构

| 引擎 | 角色 | 特点 |
|------|------|------|
| MinerU 3.x | PDF→MD 转换 | VLM渲染，高质量MD输出，处理扫描版PDF |
| PyMuPDF | 基准参照 | 快速、忠实，读 PDF 内部文字层，用于交叉验证 |

## 单篇流程

```
1. 定位 PDF，检查是否存在对应 md：
   - 有 md → 直接进入步骤 2
   - 无 md → mineru -p PDF路径 -o 输出目录，取生成的 .md 放到 PDF 同目录
2. 对比一：MD vs PDF → 输出差异对照表1
3. PyMuPDF 全篇逐页抽取
4. 逐页异常检测 → 标记可疑页/破损页
5. 对比二：PyMuPDF vs MD → 输出差异对照表2
6. 联网补缺：针对空括号，用上下文线索联网搜索补回丢失内容
7. 对照 PDF 逐处修正差异
8. 快速扫描空括号、孤立逗号、英文/数字残留
9. 输出修正汇总表（含联网补回统计）
```

**每一篇都必须走完，禁止跳过。**

## 步骤详解

### 1. MinerU 转 MD

```bash
mineru -p "PDF路径" -o "输出目录"
```
取生成的 `hybrid_auto/xxx.md` 作为工作副本。

### 2. 对比一：MD vs PDF（差异对照表1）

将 MD 与原始 PDF 逐页对比，输出差异表：

```
## 差异对照表1：MinerU MD vs PDF 原文

| 页码 | 位置 | MD 输出 | PDF 原文 | 问题类型 | 严重程度 |
|------|------|---------|---------|---------|:--:|
| 1 | 摘要第2行 | "...显著进展..." | "...取得显著进展..." | 漏字 | 中 |
| 3 | 第3段 | "（ ）" | "（2023）" | 数字丢失 | 高 |
| 5 | 表1 | 表格变形 | 正常表格 | 格式错误 | 低 |
```

### 3. PyMuPDF 全篇逐页抽取

```bash
python << 'PYEOF'
import fitz
pdf = fitz.open(r"PDF完整路径")
with open(r"提取输出.txt", "w", encoding="utf-8") as f:
    for i in range(pdf.page_count):
        text = pdf[i].get_text()
        char_count = len(text.strip())
        f.write(f"\n===== PAGE {i+1} (chars: {char_count}) =====\n")
        f.write(text)
PYEOF
```

### 4. 逐页异常检测

检查每页抽出的文字量（chars 数）：
- **文字量 < 50 字符** → 标记"可疑页"
- **出现连续乱码**（如 `□□□`、不可打印字符连片）→ 标记"破损页"
- 其余 → 正常页

### 5. 对比二：PyMuPDF vs MD（差异对照表2）

将 PyMuPDF 提取结果与 MinerU MD 逐页交叉验证：

- **正常页**：PyMuPDF 对照 MD
- **异常页**：PyMuPDF 对照原 PDF，MD 对照原 PDF，双参照
- **两引擎结果不一致处**：标记为高风险区

输出差异对照表2：

```
## 差异对照表2：PyMuPDF vs MinerU MD

| 页码 | 状态 | PyMuPDF | MinerU MD | 一致？ | 谁更准确 |
|------|:--:|---------|----------|:--:|:--:|
| 1 | 正常 | "...取得显著进展..." | "...显著进展..." | ✗ | PyMuPDF |
| 2 | 正常 | "（2023）" | "（ ）" | ✗ | PyMuPDF |
| 3 | 异常 | 乱码 | 正常文本 | ✗ | MinerU |
| 4 | 正常 | "..." | "..." | ✓ | — |
```

### 6. 联网补缺

两个差异表走完后，MD 中残留的空括号（`（ ）`）需要用联网搜索补回。空括号丢失的内容分三类，补回方式不同：

| 类型 | 占比 | 补回方式 | 示例 |
|------|:--:|------|------|
| 引用年份 | ~50% | 搜"作者名+论文标题关键词"→年份直接返回 | MD：参照俞荣建( )→ 搜"俞荣建 代工企业 2010"→补"(2010)" |
| 英文缩写/名称 | ~35% | 搜前后文中文短语，缩写固定 | MD：世界知识产权组织( )→ 搜"世界知识产权组织 缩写"→补"(WIPO)" |
| 公式/表号 | ~15% | 联网搜不到，回PDF原文查 | MD：如式( )所示→ 对照PDF页面 |

**操作方式**：对每处空括号，提取前后15个中文字符作为搜索上下文，联网检索，取返回结果中的年份/缩写填入。联网命中率约85%。联网失败的标记"需回查PDF"。

补完后重新扫描空括号数量，与补之前对比，输出补回统计：

```
## 联网补缺统计

| 类型 | 补前 | 联网补回 | PDF查补 | 剩余 |
|------|:--:|:--:|:--:|:--:|
| 引用年份 | 120 | 115 | 5 | 0 |
| 英文缩写 | 84 | 70 | 14 | 0 |
| 公式/表号 | 35 | 0 | 35 | 0 |
| **合计** | **239** | **185** | **54** | **0** |
```

### 7. 修正

对照两个差异表，逐处修正 MD 中的问题：
- 差异表1标记的漏字/丢数字 → 从 PDF 原文补回
- 差异表2标记的不一致处 → PyMuPDF 更准确的用 PyMuPDF，MinerU 更准确的保留 MinerU
- 两引擎都不对 → 人工对照 PDF

### 8. 快速扫描

```bash
grep "（ ）" md文件    # 空括号 = 内容丢失
grep " ， " md文件    # 孤立逗号 = 前面丢了东西
grep "[a-zA-Z]" md文件  # 英文/数字残留检查
```

### 9. 修正汇总表

```
## 修正汇总

| 类型 | 差异表1发现 | 差异表2发现 | 已修正 | 遗留 |
|------|:--:|:--:|:--:|:--:|
| 漏字 | 3 | 5 | 5 | 0 |
| 数字丢失 | 2 | 1 | 3 | 0 |
| 英文/数字残留 | 1 | 2 | 3 | 0 |
| 格式错误 | 2 | 0 | 1 | 1 |
| **合计** | **8** | **8** | **12** | **1** |
```

## 常见丢失模式

中英文混排处的数字、英文名、技术参数最容易被丢弃：

| 丢失内容 | PDF 原文 | md 输出 |
|----------|----------|---------|
| 引用年份 | "安同良等（2023a）" | "安同良等（ ）" |
| 英文/数字 | "DVD、5G和高铁" | " 、 和高铁" |
| 英文名+年份 | "（Teece，1986）" | "（ ， ）" |
| 技术参数 | "10—22nm，6%，10nm" | "10— ， ， " |
| 统计数据 | "22363家企业" | " 家企业" |
| 表号列号 | "表4列（1）—（6）" | "表 列（ ）—（ ）" |

## 其他差异

| 类型 | 处理 |
|------|------|
| 页眉/页码/期号混入 | 删除 |
| 引用年份折行 | 合并回一行 |
| 段落拆散 | 合并恢复 |
| 表格/公式变形 | 对照 PDF 修正 |
| 句子遗漏/字符误识 | 对照 PDF 补回 |

## 批量处理

逐篇执行单篇流程，全部完成后汇总：总篇数、每篇差异数/修正数、遗留问题。

## 实战要点

### 上下文匹配补缺

两个差异表走完后，MD 中残留的空括号用 AI 直接读上下文判断丢失内容，无需正则匹配。空括号格式为全角括号+半角空格：`（ ）`。AI 根据前后文语义推断丢失的是引用年份、英文缩写还是公式编号——命中率远高于正则模板。

### 公式与图片删除

从 minerU MD 提取前8000字时，删除所有 LaTeX 公式（`$$...$$`、`$...$`）和图片引用（`![]()`）。公式区残留的空括号无需处理——不在文献综述段落内。
