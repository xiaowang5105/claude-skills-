# hexie 素材质量分层索引

本索引用于指导 `hexie-writer` 和 `hexie-check` 读取素材。分层只决定“怎么用”，不代表材料本身学术价值高低。

## 分层标准

| 层级 | 名称 | 可用于 | 不可用于 |
|------|------|--------|----------|
| A | 完整结构模板 | 整段结构、问题链、文献群落组织、贡献定位、句层节奏、收束方式 | 当前论文事实依据；照搬原文 |
| B | 去引用后结构模板 | 删除作者、年份、政策、数据、案例、具体结论等引用信息和事实信息后的判断链、句式节奏、连接方式 | 引用事实、背景事实、整段原样模仿 |
| C | 词感语料 | 搜索 1-3 段相近表达，参考词语、短语、连接方式和非 AI 气口 | 结构模板、引用事实、背景事实、标点和引用格式 |

## 默认读取顺序

1. 先判断任务类型：引言、文献综述、理论铺垫、现实背景、研究缺口、贡献段。
2. 结构写作优先读 A 档完整结构模板。
3. A 档没有匹配类型时，再读 B 档；B 档必须先删除或忽略作者、年份、政策、数据、案例和具体事实，只学习剩余判断链和句式结构。
4. C 档只在去 AI 腔、找中文经管论文气口时局部搜索，每次最多取 1-3 段。
5. 所有政策、年份、事件、数据、企业案例、制度背景、国际形势和文献发现，都必须回到用户材料、原文、PDF、MD 或可靠来源核验。

## 人工晋级规则

只有同时满足以下条件的段落，才建议从 B 或 C 晋级到 A：

- 段落属于引言、文献综述、理论铺垫、现实背景、研究缺口或贡献段。
- 不含明显 OCR 污染、页眉页脚、断裂英文、空括号、缺失年份或错乱标题。
- 结构功能明确：背景铺垫、问题链、文献群落、机制推导、缺口收束、贡献定位之一。
- 删掉具体主题词后，句层结构仍可复用。
- 引用和事实能够回到原文或可靠来源核验。

晋级时不要整篇搬入 `structure-template-library/`。只摘取干净段落，并在新模板文件中标注“段落功能”和“可模仿内容”。如果一个文件整体是 B，但其中有少数段落达到 A，应只把这些段落单独做成 A 档短模板，不要把整份文件升 A。
