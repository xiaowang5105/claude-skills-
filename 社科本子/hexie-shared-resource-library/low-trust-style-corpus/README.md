# corpus 风格语料库

本目录用于存放中文经济学、管理学论文的风格语料，服务于 `hexie-writer` 和 `hexie-check` 的“去 AI 腔”“学术气口”“用词适配”。

## 用途

- 参考中文经管论文的内容词、连接词、句式节奏和段落气口。
- 对照识别空泛表达、AI 腔和过度模板化表达。
- 为改写提供 1-3 段局部风格参照。

## 禁止用途

- 不作为文献事实依据。
- 不用于确认某篇论文的结论、年份、期刊、数据或机制。
- 不模仿 MinerU/OCR 造成的空括号、缺年份、英文残缺、错断句、错标点。

## 原始素材

未清洗的 MinerU/OCR 转换材料和历史大素材放在 `raw/`。使用时先搜索关键词，只读取局部段落。
